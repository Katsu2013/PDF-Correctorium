# キーボードショートカット一覧

キーボード操作による効率的な作業のためのショートカット早見表です。

---

## 1. ファイル操作

| ショートカット | 操作 |
| :--- | :--- |
| **Ctrl + O** | PDFを開く |
| **Ctrl + Shift + O** | プロジェクトを開く |
| **Ctrl + S** | プロジェクトを上書き保存 |
| **Ctrl + Shift + S** | プロジェクトを別名で保存 |
| **Ctrl + E** | 修正済みPDFとして出力 |

---

## 2. 編集・履歴操作

| ショートカット | 操作 |
| :--- | :--- |
| **Ctrl + Z** | 元に戻す (Undo) |
| **Ctrl + Y** または **Ctrl + Shift + Z** | やり直し (Redo) |
| **Ctrl + F** | 検索 |
| **Ctrl + H** | 置換 |
| **Delete** | 選択中のテキスト領域・墨消し範囲を削除 |
| **Esc** | 選択解除 / 編集モードのキャンセル |

---

## 3. 画面表示・ズーム

| ショートカット | 操作 |
| :--- | :--- |
| **Ctrl + マウスホイール** | ズームイン / ズームアウト (25%〜400%) |
| **Ctrl + 0** | ページ全体を表示 (Fit Page) |
| **Ctrl + 1** | 100% 表示 (1:1) |
| **Ctrl + 2** | ページ幅に合わせる (Fit Width) |
| **F6 / Shift + F6** | 主要パネル間のフォーカス移動 |

---

## 4. 校正・確認モードの専用操作

| ショートカット | 操作 |
| :--- | :--- |
| **Enter** | 選択領域の確定 / 編集 |
| **F3 / Shift + F3** | 次の確認対象へ移動 / 前の確認対象へ移動 |
| **Ctrl + Enter** | 「確認済みに設定して次の対象へ進む」 |

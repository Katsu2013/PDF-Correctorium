# キーボードショートカット・キー操作一覧

PDF Correctorium のキーボード操作早見表です。  
標準的なショートカットキー、メニュー・パネルのアクセスキー、および設定でカスタマイズ可能な文字編集ショートカットをまとめています。

---

## 1. ファイル操作

| ショートカット / 操作 | 機能 | 備考 |
| :--- | :--- | :--- |
| **Ctrl + O** | PDFを開く | ファイル選択ダイアログを表示 |
| **Alt + F ➔ P** | プロジェクトを開く | 保存済み `.pdfocrproj` を選択 |
| **Alt + F ➔ R** | 最近開いたファイル | 矢印キーとEnterで履歴から選択 |
| **Ctrl + S** | プロジェクトを上書き保存 | 現在の `.pdfocrproj` に保存 |
| **Ctrl + Shift + S** | プロジェクトを別名で保存 | 保存方式（通常／ポータブル）を選択して保存 |
| **Alt + F ➔ E** | 編集済みPDFを別名で出力 | 修正結果を別のPDFとして安全に出力 |
| **Alt + F ➔ X** | アプリケーションの終了 | |

---

## 2. 編集・履歴操作

| ショートカット / 操作 | 機能 | 備考 |
| :--- | :--- | :--- |
| **Ctrl + Z** | 元に戻す (Undo) | 直前の編集・ページ操作・墨消し等を元に戻す |
| **Ctrl + Y** | やり直し (Redo) | 元に戻した操作を再適用 |
| **Ctrl + F** | 透明テキストを検索 | 検索ダイアログを開く |
| **Ctrl + H** | 透明テキストを置換 | 検索・置換ダイアログを開く |
| **Delete** | 削除 | 選択中のOCR領域、墨消し範囲、または選択ページを削除（文字入力欄外で有効） |
| **Esc** | キャンセル / 選択解除 | 選択の解除、墨消し未確定パスの取消、スポイト採色の中止、墨消しモード終了など |

---

## 3. 画面表示・ズーム・パネル移動

| ショートカット / 操作 | 機能 | 備考 |
| :--- | :--- | :--- |
| **Ctrl + マウスホイール** | ズームイン / ズームアウト | 25%〜400% の範囲で滑らかに倍率変更 |
| **Ctrl + 0** (または NumPad 0) | 100% 表示 (等倍 / 1:1) | 実際のサイズで表示 |
| **Ctrl + +** (または Add) | 拡大 (ズームイン) | 表示倍率を拡大 |
| **Ctrl + -** (または Subtract) | 縮小 (ズームアウト) | 表示倍率を縮小 |
| **F6 / Shift + F6** | 主要パネル間のフォーカス移動 | ツールバー ➔ ページ一覧 ➔ プレビュー ➔ プロパティ ➔ 倍率欄 を順次循環 |
| **マウスホイール** (未選択時) | プレビューの縦スクロール | 領域・墨消しが未選択の状態でワークエリアをスクロール |
| **矢印キー** | 選択領域の微小移動 | 選択中のOCR枠を画面1ピクセル単位で移動 |
| **Shift + 矢印キー** | 選択領域の10ピクセル移動 | 選択中のOCR枠を画面10ピクセル単位で大きく移動 |

## 4. 校正・確認モードの操作

校正・確認モードでは、誤操作を防ぐため枠の直接ドラッグや幾何編集が無効化され、文字の確認とステータス更新に特化した操作となります。

| 操作 / アクセスキー | 機能 | 説明 |
| :--- | :--- | :--- |
| **Alt + Q** | 確認対象の絞り込み | 「未確認・要再確認」「未確認のみ」などの条件切替 |
| **Alt + R** | 確認対象一覧へ移動 | 現在ページの対象一覧にフォーカス |
| **前の対象 / 次の対象** | 前後の確認対象へジャンプ | ボタンクリックまたは Tab で選択。ページをまたいで検索可能 |
| **確認済みにして次へ** | ステータスを「確認済み」にして次へ進む | 選択領域を確認済みに更新し、次の対象へ自動移動 |

## 5. カスタマイズ可能な文字編集ショートカット

「編集」➔「設定」➔「ショートカット」タブにて、文字単位の送り幅（間隔）調整に関する以下の8操作をお好みのキーへ変更できます。

| 操作 | 既定のショートカット | 説明 |
| :--- | :--- | :--- |
| **前の文字へ移動** | `Alt + Left` | OCR領域内の前の文字を選択 |
| **次の文字へ移動** | `Alt + Right` | OCR領域内の次の文字を選択 |
| **選択文字の送り幅を小さくする** | `Alt + Down` | 選択文字の間隔を狭める |
| **選択文字の送り幅を大きくする** | `Alt + Up` | 選択文字の間隔を広げる |
| **画像から文字幅を自動調整** | `Ctrl + Shift + A` | 行全体の文字送りを画像解析から自動推定 |
| **選択文字以降を自動調整** | `Ctrl + Shift + Right` | 選択位置から行末までの文字送りを自動推定 |
| **文字幅を等分** | `Ctrl + Shift + E` | 領域の幅に合わせて全文字の送り幅を等分配置 |
| **OCR取込時の文字幅へ戻す** | `Ctrl + Shift + R` | 読み込み直後の初期文字送りにリセット |

※各ボタンのツールチップには、現在割り当てられているショートカットキー（解除時は「割り当てなし」）が表示されます。

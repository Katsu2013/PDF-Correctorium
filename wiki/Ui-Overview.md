## 現行仕様（v1.0.0-dev.274・コミット前確認）

右側はOCR・校正、リンク、墨消し、コメント・タグと読み上げの独立パネル。パネルの閲覧だけでは編集モードを切り替えない。ピン操作でその側をまとめて収納し、固定に戻すのは個別。後から表示するパネルも側の収納方針へ従う。収納タブはアイコン付きで、展開時は収納前の幅を引き継ぐ。×で閉じたパネルは表示メニューから戻せる。

ヘッドホンは読み上げ、ツールバー右クリックは項目表示、設定は文書なしでも利用できる。ライト／ダーク／Windowsに合わせるはUIだけを変更する。

PDF Correctorium の画面構成と、各パネルの役割を説明します。

dev.213以降、右側のプロパティは「OCR・校正」「リンク」「墨消し」「コメント・タグ」の独立したタブです。各タブは移動・分割・切り離しでき、配置をアプリ共通で保存します。編集モードの変更で対応タブを選びますが、タブを見るだけでは編集モードを変えません。「表示 → 機能別プロパティ」で表示を切り替え、「標準配置に戻す」で復元できます。入力PDFの警告と読込失敗は上部共通欄、通常のリンク確認・PDF特性検査は下部ステータスバーに表示します。

dev.227以降、「表示 → OCR枠を表示」をオフにすると、枠や塗り・操作ハンドルを隠して赤いOCR文字だけを表示できます。文字選択と編集は継続できます。アプリ設定の「表示 → OCRオーバーレイ」で枠・塗りの不透明度を調整でき、設定はアプリ共通で保存されます。PDF出力は変わりません。dev.228以降、類似語・品質分析・検索から移動した一致キーワードには、枠非表示でも半透明の黄色マーカーが表示され、移動先を判別できます。

## 1. 画面構成の概要

メイン画面は、作業効率を最大化するために以下の4つのエリアで構成されています。

```
┌────────────────────────────────────────────────────────┐
│ 1. メニューバー & ツールバー (モード切替・拡大縮小など)│
├──────────────┬─────────────────────────┬───────────────┤
│ 2. ページ一覧│ 3. メインプレビュー      │ 4. プロパティ │
│   サムネイル │    (作業キャンバス)     │    パネル     │
│              │                         │  (テキスト/   │
│              │                         │   位置・属性) │
├──────────────┴─────────────────────────┴───────────────┤
│ 5. ステータスバー (表示倍率・現在の状態・ページ情報)   │
└────────────────────────────────────────────────────────┘
```

### ① ツールバー & モード切替
* **編集モード切替**:
  * **OCR編集モード**: 文字列、位置、サイズ、回転、送り幅を自由に編集。
  * **校正・確認モード**: 未確認・要確認のOCRテキストを1つずつ順番に校正（枠の誤移動を防止）。
  * **読み順編集モード**: 各領域の上に番号バッジを表示し、読み上げや抽出の順序を視覚的に整理。
  * **墨消しモード**: 機密情報の墨消し範囲（文字選択・矩形・多角形・フリーハンド）を指定・調整。
  * **リンク編集モード**: 既存の文書内／HTTP(S)リンクを表示・編集し、文字選択または範囲指定で追加。
* **表示レイアウト切替**:
  * **ページ配置**: 単一ページ表示 / 見開き表示（左綴じ・右綴じ・表紙単独表示の有無）
  * **スクロール方式**: ページ切り替え / 連続スクロール
* **表示倍率（ズーム）**: 25%〜400%のズーム、ページ幅・全体に合わせるボタン。

### ② ナビゲーションパネル（左サイドバー）
* **ページサムネイル**: ドキュメント全体のサムネイル一覧。クリックで移動、ドラッグ＆ドロップで並べ替え、右クリックメニューで回転・削除・外部ページ挿入が可能。
* **しおりタブ**: PDFのアウトライン（目次）一覧。新規しおり追加、タイトルの直接編集、ドラッグ＆ドロップによる階層構造（親子関係）の整理が可能。

### ③ メインプレビュー（中央）
* PDFページ上に、半透明のOCRテキスト枠や墨消し範囲を重ねて表示します。
* テキスト枠をクリックして選択、ドラッグで移動、周囲の8方向ハンドルでサイズ変更が可能です。
* `Ctrl + マウスホイール` で直感的にズームイン・ズームアウト。何もない領域での通常ホイールで上下スクロール。

### ④ プロパティパネル（右サイドバー）
選択中の編集モードやオブジェクトに応じた専用プロパティが表示されます：
* **OCR編集時**: 修正後テキスト、元のOCR結果、座標（X/Y/W/H）、回転角、文字送り幅、確認ステータス、コメント・タグ、ページリンク。
* **校正・確認時**: 確認対象の絞り込み、現在ページの対象一覧、前後の対象ジャンプボタン、確認済みにして次へボタン。
* **墨消し時**: 入力方式（文字選択/矩形/多角形/フリーハンド）、色パレット、スポイト採色、半透明/不透明表示切替、選択範囲の削除。
* **リンク編集時**: 指定方法・リンク一覧・移動先・編集／追加／削除／移動履歴・枠のロック・整列／サイズ合わせ・自動作成。

dev.208以降、「説明」ボタンとアプリ設定の「詳しい説明を表示する」は全モードに共通です。非表示にすると操作説明とその余白を隠しますが、選択件数・リンク先・入力PDFの警告・読み込み状況・入力エラーは表示を維持します。

リンクの整列はOCRと同じ小型アイコンの3列配置（サイズ関連／左右／上下）です。リンクは最初に選択した枠が基準、OCRの位置揃えは選択全体の外接範囲、OCRの幅・高さは指定した基準領域に従います。見た目の統一は整列基準の変更ではありません。リンク枠のロック中は移動・サイズ変更・整列・削除を禁止し、リンク先は変更できます。OCR領域の位置ロックとは保護範囲が異なります。

リンク編集パネルは Alt+K（LinK編集）、Alt+N（New範囲追加）、Alt+G（Go移動先）、Alt+D（Delete削除）、Alt+J（Jump back戻る）、Alt+R（FoRward進む）、Alt+L（Lock）、Alt+U（自動作成）を利用できます。OCR関連の注釈パネルは同じリンク操作を同じ並びで表示し、既存の入力部品との競合を避けてメニューのアクセスキーとTab移動を利用します。

### ⑤ ステータスバー（下部）
* 現在のページ番号、ズーム倍率スライダー（中央100%基準・左右別リニアスケール）、保存方式状態（通常モード／ポータブルモード）、操作メッセージなどが表示されます。

## 2. 自由な画面レイアウトとドッキング（dev.199強化）

dev.263以降、左右端へ自動収納したタブはアイコン＋文字で表示し、押せる幅を約32pxにしています。開いた幅は収納前から引き継ぎ、以前の狭すぎる保存値は補正します。展開領域の幅を変更すると次回起動にも保持します。ピンで常時表示へ戻せます。

本アプリは **AvalonDock** を採用しており、作業スタイルに合わせてパネルやツールバーの配置を自由に変更できます：

* **パネルの移動・タブ化・上下分割**:
  * 「ページ一覧」「しおり」「プロパティ」などのパネルは、ヘッダーをドラッグすることで画面の上下左右に自由に移動・再配置できます。
  * 同じ領域に重ねてタブ表示にしたり、上下・左右に分割して同時に表示することも可能です。
* **独立ウィンドウ（フローティング化）**:
  * パネルをメインウィンドウの外へドラッグして切り離し、マルチモニター環境などで独立したウィンドウとして表示できます。
* **ツールバーの上下左右配置と切り離し**:
  * メインツールバーとページ表示ツールバーは、上下左右の各辺へ固定したり、切り離してコンパクトな浮動ツールバーとして使えます。
* **配置の保存**:
  * カスタマイズした画面レイアウトはアプリ設定に自動保存され、次回起動時も同じ配置で再開できます。

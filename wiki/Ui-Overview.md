# 画面の見方と基本操作

PDF Correctorium の画面構成と、各パネルの役割を説明します。

---

## 1. 画面構成の概要

メイン画面は、作業効率を最大化するために以下の4つのエリアで構成されています。

```
┌────────────────────────────────────────────────────────┐
│ 1. メニューバー & ツールバー (モード切替・拡大縮小など)│
├──────────────┬─────────────────────────┬───────────────┤
│ 2. ページ一覧│ 3. メインプレビュー      │ 4. プロパティ │
│   サムネイル │    (作業キャンバス)     │    パネル     │
│              │                         │  (テキスト/   │
│              │                         │   位置・属性) │
├──────────────┴─────────────────────────┴───────────────┤
│ 5. ステータスバー (表示倍率・現在の状態・ページ情報)   │
└────────────────────────────────────────────────────────┘
```

### ① ツールバー & モード切替
* **編集モード**:
  * **OCR編集モード**: 文字列、位置、サイズ、回転、送り幅を自由に編集。
  * **校正・確認モード**: 未確認・要確認のOCRテキストを1つずつ順番に校正。
  * **読み順編集モード**: 領域間の読み上げ順（順番）を視覚的に整理。
  * **墨消しモード**: 復元不可能な墨消し範囲を指定・管理。
* **表示切り替え**: 単一ページ表示 / 見開き表示（左綴じ・右綴じ）、連続スクロール切り替え。
* **拡大縮小**: 25%〜400%のズーム、ページ幅・全体に合わせるボタン。

### ② ページサムネイル（左サイドバー）
* ドキュメント全体のサムネイルを表示します。
* クリックで該当ページへジャンプ。ドラッグ＆ドロップでページの並べ替えが可能です。

### ③ メインプレビュー（中央）
* PDFのページと、半透明で重ね合わされたOCRテキスト枠が表示されます。
* マウスでテキスト枠をクリックして選択、ドラッグで移動、8方向ハンドルでサイズ変更が可能です。
* `Ctrl + マウスホイール` で直感的にズームイン・ズームアウトできます。

### ④ プロパティパネル（右サイドバー）
* 選択中のOCRテキストの詳細（修正後のテキスト、元のOCR結果、座標、回転角、文字送り幅、確認ステータスなど）が表示・編集できます。

### ⑤ ステータスバー（下部）
* 現在のページ番号、ズーム倍率スライダー（中央100%基準）、警告表示などが確認できます。

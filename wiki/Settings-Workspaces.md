# 表示言語・設定プリセット

<!-- CURRENT-RELEASE-SNAPSHOT -->
## 現行仕様（v1.0.0-dev.274・コミット前確認）

文書を開かず「編集→設定」を利用できる。表示タブでテーマとOCR枠の表示・不透明度を設定する。ツールバーの項目表示は右クリックのチェックで変更し、全プロジェクト共通で保存する。

新規文書の初期編集モードと、プロジェクトに記録した編集モードは別で、保存済みプロジェクトのモードを優先する。モードだけの切替は未保存扱いにしない。左右別収納・個別固定、読み上げドック、音声と0.5刻み速度も利用できる。[読み上げ](Read-Aloud.md)。

画面の言語設定や、作業環境に合わせたパネル配置の管理について解説します。

---

## 1. 表示言語の切り替え（日本語 / 英語）

PDF Correctorium は **日本語（ja-JP）** と **英語（en-US）** の両方に対応しています。

1. メニューの **「編集」➔「設定」**（または `Alt + E` ➔ `P`）を開きます。
2. **「表示」** タブを選択します。
3. **「表示言語 (Display Language)」** のドロップダウンから希望の言語を選択します。
4. **「保存」** を押すと、画面全体のメニュー、ツールチップ、ダイアログが即座に切り替わります。
5. ポータブル版・インストール版を問わず、次回起動時もこの設定が維持されます。

---

## 2. ワークスペース配置プリセット

作業用途（校正中心、墨消し中心、ワイド画面など）に合わせて、パネルの表示・非表示や幅をプリセットとして保存できます。

* **設定のエクスポート/インポート**: 設定ダイアログの「管理」タブから、設定内容やショートカット割り当てを JSON 形式で書き出し・読み込みが可能です。
* **プリセットの登録**: 最大20件まで、お好みの画面レイアウトを名前を付けて保存できます。

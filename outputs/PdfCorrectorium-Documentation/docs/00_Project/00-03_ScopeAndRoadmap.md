現行の実装済み範囲と詳細設計の対応は[00-04 現行機能と設計の対応](00-04_CurrentImplementation.md)へ集約する。コメント・タグ、墨消し（非矩形・一括を含む）、既存PDFリンク編集・配置／ロック・限定的自動作成、文字装飾、ドッキング、編集モード保存、ツールバー項目表示は実装済みであり、下記の旧版の未実装一覧で再び残件扱いしない。

## dev.132での修正（2026-09-04）

文書情報辞書を持たないPDFへしおりと文書情報を同時追加する際、割り当て済みのしおりオブジェクト番号を次の割当位置へ反映せず、新規`/Info`と衝突する不具合を修正した。既存のしおり・文書情報・PDF 1.4／1.5・文書言語の往復診断を、情報辞書のない入力でも合格することを確認する。

## dev.131での安定化（2026-09-04）

qpdf 12.4.1／PDFium 154.0.8035へ更新し、ハッシュ固定、全外部PDF処理の期限・出力量上限・プロセスツリー終了、Windowsジョブによるメモリ／プロセス数制限を実装した。OCR・しおり・プロジェクト・ワーカー結果にも入力／出力上限を追加した。AppContainer等の権限分離、敵対的コーパス／ファジング、修復UIは継続課題であり、Version 1.0全体の完了を意味しない。

## dev.130での安定化（2026-09-04）

プロジェクトパッケージの資源上限と内包PDF完全性検証、到達不能になったページ編集用PDFの回収、qpdfの期限管理、PDFium表示・文字抽出・文書情報読込の別プロセス化を実装した。これらは既存機能の保全性と障害分離を改善するもので、未実装のVersion 1.0機能を完了扱いにはしない。敵対的入力の網羅試験、OSサンドボックス、修復・救出UIは今後の安定化対象である。

## dev.129での追加（2026-09-01）

ページ追加・削除・並べ替え・90度回転を、OCR編集と同じ順序付きUndo/Redo履歴へ統合した。ページ操作を戻した後も、それ以前のOCR編集履歴を継続して戻せる。作業PDF、OCRページ、しおり、選択状態を復元し、元PDFは直接変更しない。これによりFR-104の現行実装差は解消した。

## dev.127での追加（2026-09-01）

設定全体（8種類の編集ショートカットを含む）のJSONインポート／エクスポートと、固定パネルの幅・表示状態の名前付きプリセットを実装した。操作は「編集 → 設定 → 管理」にまとめ、保存前のキャンセルを可能にした。自由なドッキングやショートカット専用プリセットの完成ではない。[操作・対象範囲・保存形式](../../../../SETTINGS-WORKSPACES.md)を参照。以下の過去の状態説明は、その時点の記録として保持する。

## dev.123時点の実装（2026-08-30、後続改訂あり）

Version 1.0の「必須」はリリース目標であり、完了一覧ではない。現行実装はPDF表示、サムネイル、ページ操作、OCRレイヤーの可視化・編集、読み順、検索置換、レビュー状態、しおり、別名PDF出力、プロジェクト保存・自動保存・バックアップ復元、日本語/英語UIまで到達している。校正・確認モードでは現在ページの状態別対象一覧、ページをまたぐ前後移動、確認済みにして次へを利用できる。文書プロパティ編集、同期する倍率操作、ファイル引数からの起動と関連付け用アイコンも実装済みである。

一方、Google Vision、アプリ内OCR実行、ルビ編集、コメント・タグ・差分・階層別レビュー集計・監査履歴、プロジェクト移行・修復・救出、プラグイン契約、コマンドパレット等は未実装である。ページ構造操作はこの時点ではUndo対象外だったが、dev.129で解消した。

dev.123で、文書切替前の保存確認、空文字編集と領域属性の保持、品質分析の校正モード制限、全置換後の状態を修正した。操作停止約30秒後の自動保存と、未保存プロジェクトの元PDF内包による復旧用保存を追加した。ページ構造Undoはdev.129で実装済みであり、上記の大規模機能は引き続き未完了。[実装状況](../../../../IMPLEMENTATION_STATUS.md)を参照する。

## Version 1.0

### 必須

- PDF表示、ページ移動、ズーム、サムネイル
- 透明テキスト可視化（対象範囲選択、任意色、透明度、文字・枠表示）
- 行・段落中心の文字列、位置、幅、高さ、文字間隔、ストレッチ、回転編集
- 縦書き、横書き、ページ内混在、右開き・左開き
- 読み順編集モード
- ルビを別領域として管理し、読み・検索・コピー・読み上げ・出力属性を設定
- 行・段落の分割・結合
- NDLOCR-Lite、Google Vision API、既存OCR結果、透明テキストPDFからの取り込み
- NDLOCR-Liteの実行連携とGoogle Vision連携のプロバイダー境界
- ステータス、コメント、ブックマーク、タグ、差分、変更履歴
- 検索置換、全置換、1件ずつ確認
- Undo/Redo、自動保存、復元点
- `.pdfocrproj`、診断、修復、救出
- ページ回転、並べ替え、削除
- 初期表示、表紙、綴じ方向設定
- 安全な別名保存と自動検証
- 日本語・英語UI、Portable/AppData、Traceログ

### 制限付き

- 元フォント再利用は安全に再利用可能な場合のみ。
- 行差し替え保存は事前解析で安全と判定できた場合のみ。
- PDF付随データがない場合、段落・読み順復元精度は保証しない。
- 署名・暗号化・PDF/A・Tagged PDFは入力特性を検出し、編集可否と影響を明示する。

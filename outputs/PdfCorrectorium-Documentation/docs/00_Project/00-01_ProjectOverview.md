# 00-01 プロジェクト概要

## 1. 製品の位置付け

PDF Correctoriumは、PDF編集ソフトである。特に日本語書籍のOCR透明テキスト、文字領域、読み順、ルビ、縦横混在組版および回転配置の修正に重点を置く。`.pdfocrproj`は編集作業を保持する補助的なプロジェクトコンテナであり、入力と最終成果物はいずれもPDFである。

## 2. 対象利用者

- 数百～数千ページの書籍を校正する利用者
- NDLOCR-LiteやGoogle Vision APIの結果を人手で仕上げる利用者
- OCR文字列だけでなく位置、伸縮、回転、読み順を修正したい利用者
- 将来的には、高度な機能を段階的に使える一般利用者

## 4. 成功条件

1. 画像レイヤーの見た目を維持したままOCRレイヤーを修正できる。
2. 縦書き、横書き、同一ページ内の混在、右開き、斜め配置を扱える。
3. 誤字、位置、終端、伸縮、文字間隔、回転、読み順を行・段落単位で効率よく直せる。
4. 保存失敗や異常終了で元PDFとプロジェクトを失わない。
5. 出力PDFを自動検証し、破損や重複OCRを検知できる。
6. OSSとして再現可能なビルド、ライセンス表示、貢献手順を提供できる。

## 5. 非目標（Version 1.0）

- Adobe Acrobatの完全代替
- 画像レタッチ、DTP組版、ベクター図形の本格編集
- PDFフォーム作成、電子署名作成、共同レビュー
- 完全なPDF/UA・PDF/A適合保証
- 任意の破損・暗号化・独自構造PDFの無条件編集

## 6. 主要成果物

- Windowsデスクトップアプリ
- `.pdfocrproj`形式と診断・修復機能
- PDF保存・自動検証機構
- 日本語・英語リソース
- OSS公開用 `LICENSE`、`NOTICE`、`THIRD-PARTY-NOTICES.md`、貢献ガイド

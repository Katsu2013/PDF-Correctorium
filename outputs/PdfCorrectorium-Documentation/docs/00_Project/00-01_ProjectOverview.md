# 00-01 プロジェクト概要

## 1. 製品の位置付け

PDF Correctoriumは、Windows向けのオープンソースPDF総合編集・校正ソフトウェアである。スキャン文書や日本語書籍のOCR透明テキスト、文字領域、読み順、縦横混在組版および回転配置の精密な修正に加え、画質を劣化させないページ編集（並べ替え・回転・結合）、元PDFの描画命令から直接文字コードを消去する安全な不可逆墨消し、しおり（目次）作成・文書情報編集を標準で備える。
プロジェクト全体の目標として、**「日常業務において高価な市販ソフトの代わりに使える、実用的なオープンソースPDF総合エディタの実現（代替化）」** を目指している。`.pdfocrproj`は編集作業を保持する補助的なプロジェクトコンテナであり、入力と最終成果物はいずれも標準的なPDFである。

## 2. 対象利用者

- PDFの日常的な編集・整理（ページの並べ替え、回転、結合、目次作成）を行う一般のPC利用者・ビジネス利用者
- 提出用・公開用書類から機密情報・個人情報を安全に消去（墨消し）したい利用者
- 書籍やスキャンPDFのOCR透明テキストを精密に校正し、文字検索精度を向上させたい利用者
- 高額なサブスクリプションを避け、完全無料・ポータブル・完全ローカル処理（クラウド不使用）で安全にPDFを扱いたい利用者

## 4. 成功条件

1. 画像レイヤーの見た目を維持したままOCRレイヤーを修正できる。
2. 縦書き、横書き、同一ページ内の混在、右開き、斜め配置を扱える。
3. 誤字、位置、終端、伸縮、文字間隔、回転、読み順を行・段落単位で効率よく直せる。
4. 保存失敗や異常終了で元PDFとプロジェクトを失わない。
5. 出力PDFを自動検証し、破損や重複OCRを検知できる。
6. OSSとして再現可能なビルド、ライセンス表示、貢献手順を提供できる。

## 5. 目指さない範囲（非目標）

本プロジェクトは日常業務で使える市販ソフトの実用的な代替ツール化（代替化）を目指しますが、以下のような性質の項目は目指さない範囲（非目標）とします：

- **特定の市販ソフトとの100%完全互換**: 独自の内部仕様や細かなUI挙動の完全再現は狙わず、実用性と直感的な操作性を優先する。
- **本格的な画像レタッチ・DTP組版ソフトの代替**: 写真の高度なレタッチやDTP組版ソフト並みの印刷デザインレイアウト作成。
- **PDFフォーム作成、高度な電子署名インフラ**: 入力フォームの作成や企業向けPKI電子署名サーバー連携。
- **特殊なPDF規格の完全保証**: 完全なPDF/UA・PDF/A適合保証（将来的な検討対象）。
- **任意の破損・不正構造PDFの無条件修復**: 物理的に破損したPDFや独自拡張された不正構造の無条件編集。

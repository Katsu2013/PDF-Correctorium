# 09-01 プラグイン仕様

## 現行仕様（v1.0.0-dev.274・コミット前確認）

プラグインの一般利用者向け管理・導入・実行は未実装。以下は設計候補と契約であり、現在のアプリが任意の利用者DLLや.pdfocrpluginを読み込むという仕様ではない。標準Windows音声と同梱RapidOCRの利用を、汎用プラグイン機能の完成とは扱わない。
<!-- END-CURRENT-RELEASE-SNAPSHOT -->

## 方針

Version 1.0は拡張境界と契約を設計する。一般利用者向けの完全なプラグイン管理・マーケット機能は後続版候補とする。

## 配布形式

利用者向け形式はZIP互換の`.pdfocrplugin`を候補とする。NuGetは開発時の依存管理には利用できるが、一般利用者がNuGetから直接導入する方式は採用しない。

```text
plugin.pdfocrplugin
├─ manifest.json
├─ lib/Plugin.dll
├─ runtimes/win-x64/...
├─ resources/...
└─ licenses/...
```

manifestはID、版、必要アプリ版、CPU、エントリポイント、権限、ライセンス、署名情報を持つ。

## 拡張点

- OCRプロバイダー
- PDF出力/検証ルール
- 辞書・校正
- AI候補提示
- インポーター/エクスポーター

## 安全性

プラグインは同一プロセスで任意コードを実行し得るため「権限宣言だけで安全」にはならない。信頼警告、互換性確認、無効化、安全モード、障害の切り分けを設ける。将来はプロセス分離を検討する。

## ライセンス

プラグインは自身のライセンスを宣言できる。アプリ本体のApache-2.0を強制しないが、配布物内のライセンス表示と互換性確認を必須にする。

# 99-01 用語集

| 用語 | 定義 |
|---|---|
| OCR編集レイヤー | 元PDFを変更せず、文字・幾何・構造の変更を保持する論理レイヤー |
| 透明テキスト | 見えないが検索・コピー等に使われるPDFテキスト。主に`Tr=3`等 |
| 領域 | ページ上の意味・幾何的な編集単位。段落、行、ルビ等を含む |
| 行差し替え | 既存OCRの一部命令だけを置換する保存方式 |
| ページ再生成 | ページの画像等を保持し、OCRテキスト層を再構成する方式 |
| WritingMode | 横書き・縦書きという意味上の組版方向 |
| Rotation | ページ上の物理回転角度。WritingModeとは独立 |
| 縦中横 | 縦書き中の数字等を横組みにする表現 |
| ルビ | 本文とは別領域で保持し、読みとして関連付けられる文字 |
| 読み順 | コピー・読み上げ等で領域を処理する論理順序 |
| ToUnicode | PDF内文字コードをUnicodeへ対応付けるマップ |
| CMap | PDFフォントの文字コード変換に使うマッピング |
| サブセットフォント | 使用グリフだけを含む埋め込みフォント |
| `.pdfocrproj` | ZIP互換のPDF Correctoriumプロジェクト形式 |
| ADR | 重要な設計判断と理由を保存する記録 |
| ゴールデンテスト | 既知の正解となる画像・文字列・構造と比較するテスト |
| Portable | 設定・ログ等をアプリの近くに保持する動作方式 |
| SBOM | 配布物に含まれるソフトウェア部品一覧 |

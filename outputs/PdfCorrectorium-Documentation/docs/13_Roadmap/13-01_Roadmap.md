# 13-01 ロードマップ

## dev.132で完了した不具合修正（2026-09-04）

新規しおりと新規文書情報辞書のPDFオブジェクト番号衝突を解消し、情報辞書を持たない合成PDFで往復診断した。dev.131の安全性強化と残件はそのまま継続する。

## dev.131で完了した安定化（2026-09-04）

ネイティブ依存更新とハッシュロック、全qpdf／PDF出力／PDFiumワーカーの期限・出力量・Windowsジョブ制限、OCR／しおり／プロジェクト取込上限を実装した。残る安全性課題はAppContainerまたは権限縮小の評価、敵対的入力コーパスとファジング、資源テレメトリ、修復・救出UIである。

## dev.130で完了した安定化（2026-09-04）

プロジェクトパッケージに資源上限と内包PDF完全性検証を追加し、ページ編集用PDFを参照中だけ保持するセッション管理へ移行した。qpdfへ期限・キャンセル・プロセスツリー終了を適用し、PDFiumの表示・文字抽出・文書情報読込を再利用可能な別プロセスへ分離した。今後は敵対的入力コーパスとファジング、OSサンドボックス、資源使用量の可視化、修復・救出UIを進める。

## dev.129で完了した不具合修正（2026-09-01）

Phase 2の残件だったページ追加・削除・並べ替え・90度回転のUndo/Redoを実装した。ページ操作前のOCR履歴を保持し、作業PDF・OCRページ・しおり・選択状態を前後へ復元する常設診断を追加した。完全な入力特性判定など、Phase 2のその他の残件は継続する。

## dev.127で完了した小規模項目（2026-09-01）

設定のJSON移出入と、固定パネルの幅・表示状態を保存する名前付きワークスペースプリセットを実装した。[操作ガイド](../../../../SETTINGS-WORKSPACES.md)を参照。ドッキング、コマンドパレット、ショートカット専用プリセット、および下記の追加4要望は引き続き未実装。以下のdev.123等の記述は当時の状態を保持する。

### 安定化前に残る監査指摘

2026-08-30の独立確認で、(1)別文書を開くと未保存編集が消失、(2)空文字編集が保存後に復活、(3)再保存で領域属性が欠落、(4)校正中の品質分析から幅補正可能、(5)全置換後の状態が要求と不一致、の5件を再現した。これら5件はdev.123で修正し、常設診断へ組み込んだ。ページ構造Undoはdev.129で修正した。[実装状況](../../../../IMPLEMENTATION_STATUS.md)と[回帰テスト](../11_Test/11-01_TestStrategy.md)を参照する。

dev.122当時の285件の成功と、dev.123の追加回帰試験は区別する。いずれもVersion 1.0全体の受入完了を意味しない。校正モードの現在ページの対象件数も、当初要求の階層別レビュー集計とは区別する。今回の実装・文書更新でも、未実装のMUST要求を削除・完了扱いにはしていない。

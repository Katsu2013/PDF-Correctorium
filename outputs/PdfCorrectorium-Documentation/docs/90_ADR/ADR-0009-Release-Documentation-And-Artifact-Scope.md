# ADR-0009 現行設計と配布候補の扱い

状態：採用（dev.274、2026-10-30）。

## 判断

正本は最新ソースの設計MarkdownとDirectory.Build.propsである。過去のADR、図、検証結果は履歴として保持し、古い.NET 8設計や当時の最小読取版を現行の値として扱わない。現行は.NET 10、Windows APIターゲット10.0.19041.0、プロジェクト1.14／最小dev.262、設定21である。

文書処理は完全ローカル、利用者が依頼するWebリンクと更新確認を許可する。実際の入力・資源上限を明記する。墨消し済み完成PDFと、原本を含む編集プロジェクト・作業キャッシュを区別する。

設計PDFはソースから版・互換性を導出し、本文と図を描画確認する。過去のPDFを上書きせず、新しい版付きファイルへ出す。公開物はbuild-info schema 2の許可一覧と全件ハッシュで照合し、使用済みフォルダーの利用者データをコピーしない。

コミット直前の候補は、コミット済み・署名済み・独立審査済み・公開済みの成果物とは別である。GitHub Actionsの成功や署名済みMSIX更新は実施した場合だけ記録する。

## 影響

UI起動時に配布全件のハッシュ照合や全文解析を追加しない。梱包時の安全性を強め、利用者の作業ファイルと以前の検証結果を保持する。旧ADR-0001とADR-0008の当時の基盤記述は履歴であり、上記の現行値を優先する。

# ADR-0007 ページ構成編集は論理モデルを正本とする

- Status: Accepted
- Context: ページ削除・並べ替え・回転のたびにPDF全体を生成すると、文書容量×履歴数のディスク使用、I/O待ち、一時ファイル回収責任が増える。これらの操作は元PDFページへの参照と回転角だけで表現できる。
- Decision: 形式1.4の`PageSequence`へ固定ページID、元PDFページ番号、回転角を表示順に保存する。削除・並べ替え・回転、Undo/Redo、通常モード保存では元PDFを複製しない。外部ページ挿入と最終出力など物理PDFを要求する境界でだけqpdfにより一度実体化する。OCRページ、しおり、コメント、タグ、内部リンクは固定ページIDへ追従させる。形式1.4では`project.json`を正本とし、同内容のページ別JSON、元PDF参照JSON、再生成可能サムネイルを重複保存しない。
- Consequences: 通常のページ編集履歴はPDF容量に比例して増えず、元PDFを不変の正本として共有できる。プレビューと出力は論理→物理写像と回転変換を必ず通す必要がある。複数元PDFを長期参照するモデルは導入せず、外部ページ挿入時だけ単一の新しい物理元PDFへ統合する。

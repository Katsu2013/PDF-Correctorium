| ID | 要求 | 優先度 |

| FR-102 | PDFはプロジェクトなしで閲覧でき、最初の編集時にプロジェクト作成を案内する | MUST |
| FR-103 | サムネイル、ページ移動、ズーム、回転表示を提供する | MUST |
| FR-104 | ページ順変更、削除、回転をUndo可能な編集として扱う | MUST |
| FR-105 | 初期表示レイアウト、表紙単独表示、L2R/R2Lを設定する | MUST |
| FR-106 | 最近開いたPDF/プロジェクトを一覧から再読込し、設定画面で表示件数と履歴クリアを操作できる | MUST |

FR-106の確定範囲（dev.128）: 読込成功時のみ先頭登録し重複を除去する。既定10件、表示0～30件、保持は最大30件。0件は表示・記録停止で、削除とは区別する。履歴クリアは確認後、設定の保存成功で確定し文書自体を削除しない。未保存編集・失敗時の保全はFR-101と共通。履歴のパスは設定エクスポートから除外する。[手順と制限](../../../../RECENT-FILES.md)を参照。

## FR-300 表示と選択

- 可視化のON/OFF、任意色、不透明度0～100%、文字・枠・文字＋枠を選べる。
- 表示対象は現在ページ（既定）、全ページ、選択領域、検索結果から選べる。全ページは可視範囲のみ遅延生成する。
- 行選択を既定とし、段落、複数行、詳細な文字領域へ展開できる。
- 元の枠と編集後の枠を同時表示し、ガイド、スナップ、数値入力、高倍率表示を提供する。

## FR-400 OCR編集

- 誤字修正、行・段落の移動、開始・終了位置、幅、高さを編集できる。
- Unicode文字要素ごとに独立した送り幅を保持し、横書きでは文字幅、縦書きでは文字高さとして編集できる。変更時は後続文字の開始位置と行の終端を再計算する。
- 文字単位の送り幅は、数値入力に加えて選択文字の終端ハンドルから直接変更できること。選択していない文字を等幅化または連動拡縮してはならない。
- 文字単位編集は単独選択、追加・解除選択、連続範囲選択を提供する。複数選択への数値入力は共通送り幅を設定し、ハンドル操作は各文字の送り幅を同量増減して既存の比率差を維持できること。
- 行全体の長さを維持した文字幅の等分化、およびOCR取込時の文字幅への復元を提供し、Undo/Redo可能とすること。
- 文字単位の選択は、編集後の各文字の実際の送り幅を用いた当たり判定を行うこと。
- プレビュー上のOCR領域を通常クリックして選択しただけでは、水平・垂直スクロール位置を変更しないこと。校正対象一覧の選択や前後の対象への明示移動は、対象を見せるため自動スクロールする操作として区別する。
- 補正方式は文字ストレッチ、文字間隔、均等配置、混合、自動選択、位置のみを持つ。
- 横書き・縦書きは領域単位で保持し、同一ページ内で混在できる。
- 物理回転角度と文字方向を分離し、任意角度、回転中心、スナップ、0/90/180/270度を扱う。
- 行・段落を分割・結合し、所属を変更できる。
- 通常PDFテキストの不可視化、画像へのOCR追加、透明テキストの手動追加を区別して提供する。
- 編集操作はすべてOCR編集レイヤーへ記録し、確定保存まで元PDFを変更しない。

## FR-500 読み順・ルビ・出力属性

- 読み順編集を独立モードとし、番号表示、ドラッグ、直接入力、自動推定、グループ化を提供する。
- ルビは本文とは別領域とし、本文との関連、読み文字列を保持できる。
- 領域ごとに検索、コピー、読み上げ、PDF出力の対象可否を独立設定できる。
- 関連付いたルビは「読みとして使用」、未関連ルビ候補は既定で読み上げ対象外とする。
- Tagged PDFや`ActualText`を用いる高度なアクセシブル出力は段階実装とする。

## FR-600 レビュー

- 状態は未確認、確認済み、修正済み、要再確認、OCR対象外、保留を持つ。
- 状態は単一領域、段落、複数選択へ一括設定でき、変更をUndo/Redoおよびプロジェクト保存の対象とする。
- 文字列または幾何情報を編集した領域は、自動的に修正済みへ更新する。
- ページ、段落、行に状態を保持し、集計・絞り込み・次候補移動を提供する。
- コメントは文書、ページ、段落、行、文字領域、ルビ、読み順、検証結果へ付けられる。
- ブックマーク、重要度、ユーザータグを提供する。
- 文字、幾何、構造、読み順、属性の差分を表示する。

### 現行の校正・確認モード

dev.123では「未確認・要再確認」（既定）、「未確認」、「要再確認」、「すべてのステータス」で現在ページの削除されていない領域を絞り込む。対象一覧は読み順で並び、前後移動はページ順・読み順で別ページも検索する。文書端で循環しない。「確認済みにして次へ」は単一領域を確認済みにし、次候補へ進む。文字修正は修正済みとなり、既定の対象一覧から外れても編集欄は維持される。

通常の移動・変形・文字幅・追加削除・分割結合操作と、OCR品質分析のキーワード幅補正をこのモードで無効にする。文字の挿入・削除に伴う通常の文字配置再計算も行われるため、配置を絶対に変えないモードではない。現在ページの件数表示は、要求する文書・ページ・段落の階層別集計が完成したことを意味しない。操作の詳細と中止動作は[UX・操作フロー](../02_UIUX/02-01_UXAndWorkflows.md)を参照する。

## FR-700 検索・置換

- 候補を画像抜粋・文脈・ページ・方向・状態とともに1件ずつ確認できる。
- 対象範囲と状態、縦横方向を絞った全置換を提供する。
- 一括置換全体を1つのUndo操作として戻せる。
- 一括変更後の既定状態は要再確認とする。

dev.123で全置換後を「要再確認」に修正し、既定の校正対象に残るようにした。通常の単独文字修正を修正済みにするFR-600の規則とは区別する。

## FR-800 編集履歴と回復

- Ctrl+Z/Ctrl+Yを含むUndo/Redoを必須とし、既定100件、設定可能とする。
- PDFではなく編集プロジェクトを5分ごと、または操作停止30秒後に自動保存する。
- 影響の大きい処理前に復元点を作る。
- Undo履歴と監査用変更履歴を分離する。

## FR-900 保存と検証

- 保存方式は自動、行差し替え、変更ページ再生成、全文再生成から選べる。
- 既定は変更ページ再生成。自動は安全性を判定して方式を選ぶ。
- 元フォントを優先し、不足時のみ代替フォントのサブセットを埋め込む。
- 一時PDFへ出力し、検証合格後のみ目的ファイルを確定する。
- 元PDFへの上書きは既定で禁止。明示上書き時もバックアップを作る。
- 構造・描画・文字抽出・重複・位置・透明性・読み順・フォントを自動検証する。

## FR-1000 プロジェクト

- `.pdfocrproj`はZIP互換、バージョン付き、人間可読なJSON中心とする。
- 元PDFの外部参照と内包を選べる。
- コメント、ブックマーク、差分、履歴、状態、UI作業状態、検証結果を保持する。
- 安全保存、世代バックアップ、異常終了復旧、診断、修復、読み取り専用、救出モードを備える。

## FR-1100 UIと設定

- ドッキングUI、ワークスペースプリセット、コマンドパレットを提供する。
- ショートカットはAcrobatに近い既定値とし、競合検出付きで変更・移出入できる。
- 日本語・英語、Portable/AppDataを切り替え可能な設計とする。
- 高度な設定は段階的に提示し、基本操作を妨げない。
- OCRオーバーレイと編集ハンドルの色、不透明度、大きさを設定画面から変更し、即時反映できること。
- アプリケーション設定はPortableモードでは`config/settings.json`、インストールモードではAppDataへ安全に保存すること。

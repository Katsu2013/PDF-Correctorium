# v1.0.0-dev.201 — 段階的な文書読み込み

公開済みリリースではなく、dev.200からの開発スナップショットです。

## 変更内容

- 最初のページを先に表示し、全ページのリンク確認・入力PDF特性検査は文書単位のバックグラウンド処理で継続。
- リンク読込中もページ移動／スクロール／倍率変更を利用可能。リンク準備後に編集を許可し、フォント／セキュリティ特性の検査は編集を妨げず継続。
- 初期化済みプロジェクトは保存済みリンクを再利用。座標メタデータは確認するが、注釈・アクションの取り込みを繰り返さない。
- プロジェクトJSON・サムネイルキャッシュの読み込み／解析をUIスレッド外で実行。
- 全ページのフォント・文書情報検査は専用のリソース制限付きネイティブワーカーへ分離。現在ページや連続表示／サムネイル用ワーカーの待ち列を占有しない。
- リンク設定時に、移動先のページIDを得るだけの不要な画像・OCR読み込みを廃止。
- 保存・PDF出力・ページ構成変更は必要な読み込み・検査を待つ。自動保存は検査中には開始しない。
- 文書変更／終了時は古い処理を取り消す。読み込み失敗は理由を表示し、閲覧を維持しながら不完全な編集・保存を防止。

## 互換性・制限

プロジェクト形式は1.10、最小対応アプリはdev.200のままです。永続データ項目は追加していません。

初期表示前に必要な元PDFの同一性検証、埋め込みPDFの展開、初期表示設定・初期ページの準備は省略していません。ファイルサイズや保存媒体による待ち時間をゼロにする変更ではありません。すべてのプロジェクトデータをページ単位の遅延読み込みへ変えるものでもありません。

リンクの位置・サイズ合わせ／ロックはユーザーへの仕様確認待ちで、まだこのビルドには含まれません。

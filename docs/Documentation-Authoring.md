# 文書の執筆・PDF変換ルール

## 必ず守る出力形式

- Mermaidは図として描画して埋め込む。ソースコードのまま出さない。
- 図が描画できない場合は変換を中止する。既存PDFを残す。
- 本文中の短いコードにも淡い背景を付け、通常の文章と区別する。
- 通常のコードブロックは淡い背景・グレーの輪郭・内側余白で本文と区別する。
- コードが改ページされても各ページの背景と輪郭を維持する。
- 字下げを保持し、日本語コメントを含む長い行は表示幅で折り返す。

## 読みやすさの基準

| 伝えたい内容 | 推奨する見せ方 |
|---|---|
| 最初に判断してほしいこと | 章冒頭の短い要点・状態表 |
| 並列の条件・操作・注意 | 1項目1論点の箇条書き |
| 違い・対応状況 | 比較表 |
| 処理順・分岐 | フロー図・シーケンス図 |
| 所属・データの関係 | 構成図 |
| 過去の検証結果 | 日付・版を残してarchiveへ分離 |

- 図には対象と状態を明記する。未実装の構造を実装済みとして描かない。
- 箇条書きへの変更で例外・否定・安全条件を省略しない。
- 詳細仕様へのリンクを残す。要約だけを正本にしない。
- 過去の試験件数は当時の記録として扱い、再実施したように書かない。

## 生成と確認

1. 固定依存を復元する。手順は[レンダラーの説明](../tools/documentation-renderer/README.md)を参照する。
2. リポジトリ直下から変換ツールを実行し、新しい版・日付の出力先を指定する。
3. Mermaid件数と埋込み図を照合する。
4. ページ画像でコードの枠・文字・改ページを確認する。
5. 相対リンクと、現行／計画／履歴の区別を確認する。

```powershell
python tools/BuildDocumentationPdf.py `
  --source-root outputs/PdfCorrectorium-Documentation `
  --output <新しい出力PDFのパス> `
  --chrome 'C:\Program Files\Google\Chrome\Application\chrome.exe'
```

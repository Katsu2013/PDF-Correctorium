# 共通の読み方・ルビ編集・読み上げパネル（dev.262）

2026-10-29。利用者確認済みの方針を実装する。

## 読み方

プロジェクト全体の共通辞書と既存の行ごとの読み方を併用する。同じ表記に行の指定がある場合は行の指定を優先し、完全一致・最長優先・Unicode書記素の境界を音声とルビで共用する。共通辞書の変更時に全ページを読込み・書換えない。読み込み済みの行は照合キャッシュを無効化し、未読込ページは表示／読み上げ時に辞書を適用する。共通辞書と行指定は別に編集・削除でき、共通辞書を削除しても行指定は消さない。Undo／Redo、保存と再読込に対応する。

プロパティに適用範囲「この行だけ／プロジェクト全体」を用意する。ルビはダブルクリックで小さな編集欄を開き、表記・よみ・適用範囲を確認して更新する。元のOCR文字や枠は動かさない。dev.262時点ではPDFへのルビ／読み方埋込みを対象外としていた。dev.267では確認用ルビは描画せず、読み方をPDFの代替テキストへ保存する。[現行の出力設計](Pdf-Reading-Export.md)を参照する。

プロジェクトへ共通WordReadingsを追加する。旧版による辞書の黙示的な喪失を避けるため、保存形式1.14／最小読込dev.262とし、旧1.0～1.13は読み込める。これはアプリのリビジョン変更だけを理由とする形式更新ではない。

## 読み上げパネル

読み上げ内容を再利用できるコントロールへ分離し、独立したAvalonDockパネルとして表示する。初期位置は右、既存のヘッドホンボタンとメニューで同じパネルを開く。ドッキング・浮動化・タブ切替・自動収納では再生器を作り直さず、再生位置と一時停止を保持する。隠したパネルを再表示しても同じ状態へ戻る。アプリ終了時に取消・音声資源を解放する。初回に開くまで音声の列挙・合成器は初期化しない。

狭いパネルでは操作を折り返し、既存32単位の操作ボタンを保持する。再生・停止・前後移動、段落／行、範囲、音声・0.5刻み速度の意味は維持する。

## 自動収納・配置復元

dev.266では、収納は同じ側を一括、固定へ戻すのは選択パネルだけへ統一する。後から開く読み上げもその側の収納設定へ従い、個別固定の例外とともに保存する。[現行の収納仕様](Chapter-Grouping-And-Side-AutoHide.md)。

dev.263でタブの表示寸法と幅継承を補強する。アイコン＋文字の32px幅、ネイティブのピンによる幅継承、狭い旧保存値の補正、有効な展開幅の保持は[追加仕様](AutoHide-Tab-And-Width.md)を正とする。

プロパティ各パネルと読み上げを左右端のタブへ収納し、クリックで一時表示、ピンで固定表示へ切り替える。表示メニューからも固定／自動収納を明示的に選べる。通常の非表示とは区別し、既存のパネル復活操作を保持する。自動収納を編集モード切替で勝手に解除しない。

ネイティブのレイアウト保存を使い、左右位置・幅・固定／自動収納・浮動を次回起動へ復元する。旧レイアウトには読み上げだけを非表示状態で追加し、他の配置を初期化しない。配置のための設定形式は21を維持する。移動・収納後の空白、パネル消失、再起動とモード切替時の位置、保存XMLの検証を回帰確認する。

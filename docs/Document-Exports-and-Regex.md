# 文書データ出力・正規表現墨消し候補 — dev.225

2026-10-14。既存機能との重複は[Wikiの照合表](../wiki/Roadmap.md)へ記録した。実装順はOCR TXT → 独自コメントCSV → PNG/JPEG → 正規表現候補検索。

## 1. TXT・CSVは校正作業データ

利用者確認済み：墨消し予定の文字やコメントを含み得る作業用出力とする。保存前の画面に常時注意を表示し、機密共有向けの墨消し済み成果物と誤認させない。OCR TXTは編集後・削除領域除外・現在のページ順と読み順を使い、ページ区切りと対象範囲を指定できる。画像だけでOCR情報がないページで新たな認識は行わない。コメントCSVは独自コメントとタグのみ。標準PDF注釈の新規取込やXFDF互換を意味しない。

UTF-8（CSVはBOM付き）、引用符・改行を正しくエスケープする。Excel等で式になる先頭文字・空白制御文字を保護し、文字の意味が無断で式として評価されないようにする。出力バイト／文字／件数を制限する。原PDF・プロジェクト等の入力を上書きしない。既存出力への置換はファイル選択時に確認し、作業途中の不完全ファイルを確定名にしない。

## 2. PNG/JPEGはPDF出力と同じ完成状態

ページ範囲、PNG/JPEG、DPI（72〜300）、JPEG品質を明示する。画面キャプチャではなく、現在の編集を既存の検証付きPDF出力へ通し、その完成PDFのページを描画する。半透明の墨消し予定枠・OCR編集枠・ハンドルを画像へ含めない。暫定PDFは専用領域1件だけで、入力は隔離ワーカーへ処理単位で1回だけコピーする。1ページずつ画像を保存し、全ページ画像をメモリや一時PNGに溜めない。

PDFium・qpdfのAppContainer、Job制限、ハンドルによる出力実体／サイズ／寸法検査を維持する。画像操作用の専用クライアントを用い、通常のページ移動用ワーカーへ大量要求を並べない。入力の共有は処理単位に限定し、異なる文書や次の操作へ残さない。ユーザー指定親フォルダに生成した専用サブフォルダへ固定命名で出力し、既存ファイルを上書きしない。取消／失敗では生成途中フォルダを限定清掃し、成功時だけ完成フォルダを表示する。大き過ぎる画素数や異常なページ寸法は明確に拒否し、勝手な画質低下で成功扱いしない。

初回実装では、画像の対象範囲が一部でも完成PDFの生成・検証は文書全体へ行う。この準備時間と画像化時間は別に進捗を表示する。速度のために未検証PDFや墨消し予定の半透明表示を保存する経路は設けない。DPIは72〜300、1画像は最大8,192画素／辺・2,000万画素・64 MiBで、超過時は拒否する。

入力上書き保護には既に利用者が選択・認可したPDF・プロジェクト・OCR伴走ファイルだけを使う。プロジェクト内の未検証な絶対パスヒントを存在確認しない。ネイティブ起動・ステージング・画像符号化・ワーカー停止は背景処理とし、処理専用ワーカーの入力共有は終了時に破棄する。

## 3. 正規表現は既存の墨消し候補UIへ統合

既定は従来どおり完全一致。文字列一括墨消しの画面に「正規表現」を追加する。無効な式・空文字一致・過大な式、検索時間／全文字量／結果件数の上限超過は候補生成を中止する。失敗時の部分候補を適用可能にしない。文字列と字形のUTF-16範囲対応を使い、実際に一致した字形だけを既存の候補・墨消し処理へ渡す。サロゲートの一部に一致した場合も字形単位で扱う。OCR認識誤りや画像だけのページは検出保証外。

候補一覧とプレビューを確認してから選択したものだけ適用し、1回のUndoで復元する。候補作成では文書を編集せず、文書／編集世代や条件が変わった場合の失効を維持する。JavaScriptや外部コードを実行しない。個人情報の完全自動検出とは表記しない。

実装値は式1,024文字、1回の一致評価200ms、累積一致評価5秒、本文1,600万文字、最大10,000一致。累積評価時間は描画待ち時間を含めず、全文書を1つの予算で扱う。既存のOCR検索・置換画面の正規表現とは対象操作を区別する。

## 4. UI・受入条件

ファイルメニューの出力サブメニューと単一の出力ダイアログを設ける。主要操作には既存アイコンを再利用し、ダイアログ下部の実行・中止・閉じるは文字のみ。処理中は条件を固定し、進捗・取消・完了先・失敗理由を示す。処理は非同期で、入力待ちや表示スクロールを長時間ブロックしない。

検証対象：編集後／空欄／削除／読み順・ページ順、CSVの式注入・引用符・改行・タグ、入力上書き拒否、正規表現の無効式・ゼロ長・時間制限・字形対応・Undo、PNG/JPEG解像度・編集反映・墨消し・単位入力コピー・取消清掃・安全な出力パス。Releaseビルド、契約、関連UI／セキュリティ診断と配布版でのバージョン一致を確認する。データ形式・最低読込版は新しい永続項目を追加しないため据え置く。Git公開・証明書署名・第三者承認は本作業に含めない。

FEATURES

PDF Correctorium の3つの主な特長

🛡️

指定範囲の文字を除去する墨消し

対象範囲の文字データを除去し、本文文字の残存を出力時に検査します。同じ情報が別ページ・文書情報・添付ファイルにも存在する場合、それらは別途確認してください。原本を保持する編集用プロジェクトは、完成した墨消し済みPDFとは区別します。

  • ✓ 文字選択・矩形・多角形・フリーハンド対応
  • ✓ 周囲の文字や画像の鮮明さを保つベクター保持
  • ✓ 出力後に文字が残っていないかの自動チェック機能
  • ✓ 背景色に自然に合わせるスポイト機能
✏️

国会図書館OCR連携 & 精密校正

スキャン文書の透明OCRテキストの誤認識、位置ズレ、文字ごとの間隔を視覚的に修正。国立国会図書館「NDLOCR-Lite」出力の取り込みにも対応。

  • ✓ 誤認識テキストの打ち直しと文字枠の微調整
  • ✓ 日本語の縦書き・横書き混在と読み順の整理
  • ✓ 未確認の文字をテンポよく確認する「校正・確認モード」
  • ✓ 書類全体の一括検索・置換 & 品質診断
📑

画質無劣化のページ整理 & しおり

サムネイルのマウス操作でページの並べ替え・回転・結合。通常のページ整理では元画像を不要に再圧縮しません。画像最適化や範囲墨消しなど、画像変換を伴う機能とは区別します。

  • ✓ ドラッグ＆ドロップによる直感的な並べ替え・回転
  • ✓ 他のPDFファイルから必要なページを差し込み結合
  • ✓ クリックで飛べる階層目次（しおり）の作成・編集
  • ✓ 元データを上書きしない安心のプロジェクト保存
⚡ 元データを壊さない安全設計 作業履歴は .pdfocrproj に保存。
いつでも何度でも元に戻せます。
🔒

なぜ「完全ローカル・オフライン」なのか？

Web上のオンラインPDF編集サービスは手軽ですが、「大切な機密書類、契約書、顧客情報、医療記録が外部サーバーにアップロードされる」という重大な情報漏洩リスクを抱えています。

PDF Correctorium はPDFの読込・OCR・編集・保存をお手元のPC内で完結し、PDF・OCR本文をクラウドへ送信しません。利用者が実行するWebリンクの表示や更新確認では通信します。組織での利用は、それぞれの運用基準に沿って確認してください。

クラウド送信ゼロ

文書処理のためにPDF・OCR本文を外部サーバーへアップロードしません。

回数・期限・利用料の制限なし

課金による利用制限はありません。巨大・破損入力からPCを守る処理上限があり、超過時は処理できない場合があります。

完全ポータブル

管理者権限（インストール権限）のない社用PCでも、ZIPを展開するだけで利用できます。

FAQ

よくあるご質問

Q. 本当に商用利用も含めて無料ですか？

はい、本ソフトウェアはオープンソースの Apache License 2.0 のもとで配布されており、個人の私的利用はもちろん、企業・法人・官公庁での商用利用も含めて完全無料でご利用いただけます。追加料金や広告表示も一切ありません。

Q. 会社のPCに管理者権限（インストール権限）がありませんが使えますか？

はい、ご利用いただけます。本アプリはポータブル設計となっており、インストーラーの実行やレジストリへの書き込みを行いません。ZIPファイルを解凍するだけで、お好みのフォルダーやUSBメモリから即座に起動できます。

Q. 機密情報を含む書類を読み込んでも情報漏洩の心配はありませんか？

文書処理はPC内で完結し、PDF・OCR本文を外部サーバーへアップロードしません。通常の文書処理はオフラインで利用できますが、Webリンク・更新確認には接続が必要です。共有する場合は完成PDFを確認し、原本を含み得るプロジェクト・バックアップ・作業キャッシュを混ぜないでください。

Q. 起動時に「WindowsによってPCが保護されました」と表示されます

配布物の署名や利用実績などにより、Windows SmartScreenが表示される場合があります。公式リリースから取得したか、版番号と公開SHA-256、署名がある版では発行元を確認してください。確認できないファイルを警告だけで判断して実行しないでください。

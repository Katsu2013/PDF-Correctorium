# 読み上げの前後移動・手動段落指定（dev.257）

2026-10-28。利用者確認により、移動単位は段落／行を切り替え、手動段落は行を保持してプロジェクトへ保存する。

## 読み上げ

dev.258ではメインツールバー右端のヘッドホンからも読み上げウィンドウを開ける。既存ウィンドウを再利用し、表示だけで再生しない。ボタンの表示設定はアプリ共通で保存し、表示メニューからも復元できる。

dev.259では幅500のコンパクトなウィンドウとし、最大化・サイズ変更と下部の「閉じる」を設けない。終了は右上の標準×を使う。音声設定の開閉に合わせ高さを変え、長い内容は縦スクロールで操作する。再生等のヒット領域は32単位を維持する。

読み上げ画面に「前へ／次へ」と「移動単位：段落／行」を追加する。段落単位は前後の段落の先頭へ移り、行単位は前後の行の先頭へ移る。段落の途中の行へ移った場合も、その行以降の同じ段落は連続して読む。単位を行へ変えても通常の再生を行ごとに切り直さない。

一時停止中は、移動先とマーカーだけを変え、再開するまで音声を開始しない。「現在ページから最後まで」では最初に選んだページから末尾までの範囲でページをまたぎ、空のページを必要になった時にだけ調べる。確認済みの空ページはページ番号だけを記録し、再抽出を省く。空ページしか残らない場合は先へ進むボタンを無効にし、直前の段落を勝手に再生しない。一時停止状態と現在位置は保つ。「現在ページ」「選択部分」はその範囲外へ進まない。

停止・読み終わった後も位置を保ち、前後ボタンでその位置から読み直せる。「再生」は現在の範囲設定から新しく開始する。手動のページ移動、文書の切替、文字や段落指定の編集で古い位置を無効にする。通常の枠移動だけの場合の既存のマーカー追従は維持する。前の合成から遅れて届いたイベントを破棄する。

移動単位は読み上げ画面内の設定で、プロジェクトの編集モード・未保存状態は変えない。起動時の自動再生、全文の先読み、クラウド通信は追加しない。

## 段落編集と共通にする

dev.264では、この共通分割を使って段落全体の外枠を描画する。全段落を薄く、選択中だけ強調し、既存の枠表示／不透明度に従う。[表示と性能](Paragraph-Outlines.md)。以下の「まとめる」の制限は変更していない。

従来は段落編集が近接する枠をたどる方式、読み上げが折返しを推定する方式で、同じ段落にならない場合があった。両方を同じCoreの段落分割へ接続し、明示指定を優先する。

1. OCRの行編集でCtrlを使い、読み順が連続する2行以上を選ぶ。
2. プロパティの段落指定で「まとめる」を選ぶ。選択した行を同じ段落に設定する。
3. 段落編集へ切り替えてどれか1行をクリックすると、同じ指定の連続行を選択する。読み上げも同じ区切りを使う。
4. 誤って連結される行は「行ごと」で独立した段落にする。「自動」は手動指定を解除し、同じ指定の行全体を自動判定へ戻す。
5. 操作は1回のUndo／Redoに対応し、プロジェクトの保存・再読込・復旧に保持する。

読み順が飛んだ選択は、間の未選択行を勝手に巻き込まないよう「まとめる」を無効にする。dev.266からは、Chapterと縦書きの1のように異なる書字方向・読み進む方向でも、手動で同じ段落へ指定できる。自動判定は方向の違いで区切る。枠の位置・サイズ・回転・文字・文字送り・位置固定は保持し、幾何ロック中でも段落メタデータは編集できる。既存の「隣接OCR領域を結合する」とは別の操作で、OCR領域数を減らさない。[追加仕様](Chapter-Grouping-And-Side-AutoHide.md)。

自動判定は行間・字下げ・サイズ・親ID等を考慮する。手動指定はそれらの差を越えて連結できるが、読み上げでは墨消し・対象外・削除・非連続の文字選択等の保護境界を優先する。ページをまたぐ1つの段落指定は対象外。

## 保存と互換性

OcrTextRegionのParagraphGroupIdはnullで自動、空GUIDで行ごと、同じ非空GUIDで明示段落を表す。既存のParentRegionIdを上書きしない。編集スナップショット、Undo、読込／保存／読み上げへの変換に保持する。PDFの文字配置・内容の変更としては扱わず、段落指定だけで透明文字を再配置しない。

保存形式を1.13、最小読込版をdev.257にする。これは段落指定を旧版で失わないための変更で、単なるアプリ改版への追従ではない。既存1.0〜1.12は引き続き読み込めるが、今回の版で保存後はdev.257以降で開く。設定形式21と依存ライブラリは変更しない。

## 確認項目

段落／行の前後移動、行途中からの連続読み、再生中の取消、一時停止の保持、停止後・読み終わり後の移動、範囲とページ境界、空ページ、古い進捗イベントの拒否を確認する。段落指定は保存・再読込・Undo／Redo、固定・文字送り保持、自動判定との共通化、非連続選択の拒否を確認する。公開CIへ私的なPDFを含めない。

Natural音声の制約は[dev.256の調査](Read-Aloud-Paragraphs.md)を維持する。

# 一覧表示 — 基本情報と詳細情報の整理

現行dev.241、2026-10-25（基本表示の整理はdev.238）。項目数を一律に減らすのではなく、日常の判断に使う情報を最初に示し、根拠を調べる情報を必要時に開く。分析条件・検出基準・編集データは変更しない。

## 共通規約

- 対象の識別、比較する本文、適用可否、固定・修正不可・安全上の注意は基本表示に残す。
- 列見出しの右クリックで標準のチェック付きメニューを開き、列ごとに表示・非表示を切り替える。従来の「詳細列」チェックボックスは置かない。技術的な列は初期非表示、基本の列は初期表示。変更は画面を閉じるまで有効で、表示設定の永続化は今回追加しない。
- メニューは複数の列を続けて切り替えられるよう開いたままにする。項目順は現在の列順、文言は現在の表示言語と一致させる。「既定の列表示に戻す」は列の表示だけを既定へ戻し、列順や幅は変更しない。最後の可視列は非表示にできない。列の非表示は並べ替え解除ではない。
- 一覧にフォーカスがある状態のShift+F10／メニューキーでも同じメニューを開く。結果が空でも利用可能。データ行の右クリックは列メニューへ奪わず、列見出しの余白を含むヘッダー範囲だけを対象とする。
- 列を隠してもデータは削除しない。既存の行、選択、並べ替えを保持する。隠れた列でソート中ならその順序も維持し、詳細を開けば列見出しを確認できる。
- 画面内の切替で全文再分析、画像解析、OCR、PDF再読込、履歴追加、未保存化を行わない。共通のListDetailsは列だけを変更し、行は走査しない。メニュー生成・チェックの同期も列数に比例する。
- 初期のOCR固定済みフィルターと列の表示設定は独立。基本表示では固定／修正不可の状態が分かる。必要に応じて利用者が基本列も個別に非表示にでき、既定へ戻せる。列を隠しても修正可否・ロック等の制約は解除しない。類似語の16 DIP・差分強調・生の値のソートとコピーは維持する。
- 列表示は標準ContextMenu／MenuItem、フォントは既存の展開操作を使う。ダイアログ下部の確定・取消ボタンは文字のみ。既定で安全上の情報をツールチップだけへ移さない。

## 変更する一覧

| 一覧 | 基本表示 | 詳細・整理内容 |
| --- | --- | --- |
| 文字数の外れ値 | ページ、判定、OCR文字列、文字数、目安文字数 | 密度比、比較件数、幅、高さ、方向、固定は詳細列。固定済みを表示した場合は判定にも固定済みを併記 |
| キーワード幅の補正 | ページ、文字列、差（%）、固定 | 現在幅、基準幅、方向は詳細列 |
| 類似語・誤認識候補 | ページ、現在の語、修正候補、注意、前後の文章 | 出現数、基準語数、長い理由は詳細列。固定済み・修正不可／ほかの候補ありは基本の注意に残す。完全な理由はツールチップでも確認可能 |
| OCR検索・置換 | ページ、一致部分を強調した本文 | 内部の一致位置番号は詳細列。実際の移動・置換位置は変更しない |
| 共通領域の反映候補 | 選択、ページ、一致度、現在の文字列、状態 | 数値座標は詳細列。原画像のプレビューと適用条件は維持 |
| 文書プロパティのフォント | フォント名、埋め込みの有無 | 各行を初期折りたたみにし、種類・エンコーディング・実フォント名は展開時に表示。未埋め込みも基本表示で分かる |
| 入力PDFの注意事項 | 重大度・分類・タイトル・説明 | 内部診断コードだけを行のツールチップとアクセシビリティのHelpTextへ移す。警告本文を隠さない |
| 一括墨消し候補 | 既存の候補選択・ページ・文字列・注意 | 墨消しで意味のない空の「移動先」列だけを非表示。自動ページリンクでは元ページ・移動先を必ず表示 |

## 監査したが減らさない一覧

| 一覧 | 判断 |
| --- | --- |
| 画像最適化の候補 | 対象選択、ページ、処理、現在／推定サイズ、削減量、注意は効果と適用可否の判断に必要 |
| 復旧プロジェクト | 名前・保存場所・日時・サイズは復旧／削除する版の取り違え防止に必要 |

| メイン画面のページ・しおり・OCR領域・リンク・墨消し・確認対象 | 選択・階層・読み順・行先・状態は操作に必要。今回の結果表の整理を理由に非表示にしない |

## 検証

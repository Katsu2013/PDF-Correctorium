# 類似語分析の進捗・継続修正・座標整合 — dev.226

利用者報告の5点を対象とする。通常読込メッセージのステータスバー移動は今回の変更には含めない。

この文書はdev.226時点の変更記録。現行dev.235では、下記の「外部編集・Undo／Redoですべて失効」を見直し、OCR行の配置だけの変更とそのUndo／Redoでは一覧を維持する。文字・削除・固定・ページ／文書変更の失効は継続する。[現行仕様](Similar-Word-Analysis.md#配置調整と分析の現在性dev235)、[検証](releases/v1.0.0-dev.235.md)を参照。

- 進捗：共通ProgressBarテンプレートのWPF必須部品PART_Trackを復元し、割合に応じた表示幅を検証する。全文書の収集と比較を連続した進捗で示し、ページごとの入力PDFコピーを処理単位へまとめる。
- 継続修正：修正済み候補だけを取り除き、同じOCR領域の残候補は修正前の文字範囲から差分長を用いて移動する。原文一致・非重複を再検証する。頻度は分析時の値として保持し、毎回の全文書再分析は行わない。外部編集・Undo／Redo・文書切替では従来どおり失効し、古い候補を適用しない。
- 閉じ括弧の混同：英数字の技術用語に隣接した未対応の`」`を候補文字として保持し、j／Jとの混同を比較する。対応する`「`を閉じる括弧と単独の括弧は語に含めない。日本語句読点の一括置換ではなく、候補確認後の修正に限定する。
- 差分：現在語と修正候補の相違する文字部分を赤・太字・下線で表示し、文字列そのものは変えない。最大64文字の有界比較を表示したセルだけに実行する。
- 移動時の表示：分析用96px画像と表示用プレビューの座標系を混同しない。共通のプレビュー寸法計算から、分析時点でOCRモデルを通常表示と同じ座標へ変換する。画像は低解像度のまま破棄し、モデルのID・Undo参照は後から置換しない。保存、文字送り、回転ページ、検索・一括調整にも回帰検証する。

形式1.11／最低読込dev.206／設定20は変更しない。原PDFは不変。候補が全誤認識を検出する保証はなく、分析時頻度を更新したい場合は再分析する。Releaseビルド、契約、実画面の進捗幅・差分、部分修正継続・Undo失効、座標・保存と配布版の同一リビジョンを検証する。

旧版で表示崩れの後に誤った座標を保存したプロジェクトの自動復元はしない。意図的な小領域と区別できないためで、該当する場合は保存前のバックアップや元のOCRデータと照合して復旧する。今回の修正は低解像度キャッシュから新たに誤座標を生成・保存する経路を防ぐ。

# 読み上げ速度の0.5刻み対応（dev.260）

2026-10-28。利用者がWindows標準APIと音声一覧の切替を承認したため、System.Speech／SAPIからWindows.Media.SpeechSynthesisとMediaPlayerへ切り替える。

## 操作と速度

速度は従来と同じ−5〜＋5、0は標準とし、スライダー・矢印キーで0.5刻みに調整する。値は整数へ切り捨てず、そのまま音声サービスへ渡す。表示も＋0.5、−1.5等に対応する。変更は次に生成する読み上げ区間から反映する。

新APIのSpeakingRateには `3^(調整値/10)` を渡す。従来の調整尺度に沿う対数的な速度とし、0.5は隣接する整数値の中間になる。表示値は倍速を意味しない。音声ごとの標準速度まで同じとは扱わない。

端末に導入済みのWindows標準音声を列挙する。この環境ではMicrosoft Ayumi／Haruka／Ichiroを確認した。保存された「Microsoft Haruka Desktop」のような既知のDesktop名は、対応するWindows側の名前がある場合に引き継ぐ。該当しない音声は表示言語・Windows既定音声の順で選ぶ。ナレーター専用のNatural音声の登録や、音声の自動インストールは追加しない。

## 軽快さ・進捗・中断

読み上げ画面を開いたときに専用STAと合成器を遅延生成する。通常のPDF起動に音声初期化を追加しない。既存の約2,000文字以内の区間だけを非同期に合成し、音声ストリームから直接再生する。全文・全ページの先行合成や、通常動作でのWAV一時ファイルは作らない。

時刻付きのSpeechWordキューが再生された時点で入力文字位置を通知する。既存の段落／行オフセット表とマーカーを共用し、合成が終わった時点を読み上げ位置として通知しない。前後移動・停止・文書変更で取消し、古いイベントを拒否する。再生器・メタデータイベント・ストリームを区間ごとに解放する。一時停止は再生位置を保ち、再開時に継続する。

## 設定・配布の互換性

設定21へ任意の `FineSpeechRate`（double）を追加し、欠落時は従来の整数 `SpeechRate` を使う。書き込み時には従来フィールドも最寄り整数で保持するため、旧版で他の設定まで読めなくなる事態を避ける。旧版で保存し直すと小数精度が失われ得る。非有限値を拒否／正規化し、有効な値は範囲内の0.5刻みに揃える。設定画面・保存・移出入・同時起動時のマージでも保持する。プロジェクト形式1.13／最小読込dev.257は変更しない。

アプリのWindows APIターゲットを10.0.19041.0へ変更する。Microsoft.Windows.SDK.NET.Ref 10.0.19041.57の投影・ランタイム資源と公式ライセンスを固定し、System.Speechを配布から外す。自己完結型の.NET 10.0.14と従来のPDF/OCR資源は維持する。

## 確認

実際のミュート再生で、0・0.5・1の音声時間の大小、一時停止中の再生位置、取消と直後の再利用、文字位置キューを検査する。既存の段落／行移動・空ページ・古いイベント拒否も回帰確認する。設定の保存／再読込・移出入と旧整数値を確認する。最終結果は[dev.260](releases/v1.0.0-dev.260.md)へ記録する。

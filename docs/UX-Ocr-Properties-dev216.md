# OCRプロパティ改善設計 — dev.216

2026-10-07。承認済み改善方針の第1段階。最終実装版はdev.217（dev.216の中間ビルドでの確認後、校正モードの説明を明確化）。対象はOCR・校正パネル。既存の4パネルのID・配置・編集モード・Undo契約は維持する。

## 編集単位と説明重複（dev.247）

- 編集単位は「段落 → 行 → 文字」。表示順を列挙値の番号から切り離し、Tagの値で動作と対応付ける。内部番号、初期値の行編集、既存の校正モード切替は維持する。
- 調整が共通の理由で使用不可なら、その理由は1回だけ表示する。行全体／選択文字以降がそれぞれ使えるときは2つの範囲を表示し、末尾文字などの固有理由は残す。1文字の行と位置固定の理由は区別する。
- 未選択案内は上部の現在対象へ集約する。文書の全ページや画面ツリーを走査して重複を探す実装にはせず、選択とコマンド状態だけで決める。[変更・検証](releases/v1.0.0-dev.247.md)。

## 現行のコンパクト配置（dev.240）

- 確認ステータスと文字方向を同じ行へ置き、各入力欄を約半幅とする。ラベル、名前付き入力、Alt+S／Alt+D、複数選択への適用条件、縦横書きの幾何制約は維持する。
- 画像調整は既存アイコン付きの「行全体」「選択文字以降」を横並びにする。セクションの「画像に文字境界を合わせる」で作用を示し、完全な操作名はアクセシビリティ名と既存のツールチップへ残す。対象範囲・不可理由はボタン列の直下に表示し、ヘルプOFFでも隠さない。dev.247以降、共通の不可理由は1回だけ表示する。行編集では後者とその状態を従来どおり非表示にする。
- 利用可能な内容幅264 DIP以上で2列、未満では1列。標準UniformGridと幅だけを見る変換で配置し、入力コントロールを作り直さない。8 DIPの間隔を取り、通常の文字サイズ・30 DIP以上のボタン高さを維持する。長い選択値は折り返し、候補のキー入力検索はDisplayNameで維持する。
- RapidOCRの再認識、文字サイズ推定、ロック・コマンド可否、Undo、PDF出力は変更しない。リサイズ・翻訳でOCRの再実行やページ描画を追加しない。現行の設定形式21、プロジェクト形式1.11／最小読込dev.206は変更しない。
- 下記の情報順・安全条件は引き続き有効。検証と配布は[dev.240](releases/v1.0.0-dev.240.md)を参照する。以下の版番号・検証計画は導入時の記録。

## 情報と操作の順序

1. 現在の対象：PDFの物理ページ、選択したOCR領域数、主選択行の文字選択数。未選択は明示する。
2. 状態：OCR編集／校正／読み順などの現在の文脈、領域固定、文字固定。固定は文字の削除禁止と同義にしない。
3. 頻用操作：文字・行の編集と画像による境界調整。画像調整は「選択行全体」「選択文字以降」を文字付きボタンで区別する。各操作の作用範囲と不可条件を短く隣接表示する。ボタンは同じ文脈内で位置を入れ替えない。
4. 詳細：読み方、座標、寸法、回転を折りたたむ。現在の選択を変えても展開状態を勝手に変更しない。領域の固定操作は折りたたみの外へ残す。
5. OCR領域削除は内容の後。確認ダイアログを増やさず、既存のUndoを維持する。

## 説明とキーボード

OCRの長い一般説明は、明示的に開く「操作ガイド」へ移す。他パネルの従来の説明ON/OFFは今回変更しない。現在対象、調整範囲、条件不足、入力エラー、読込進捗、安全警告はヘルプにせず常時残す。

既存のアクセスキー、名前付き入力欄、数値スピン、DelとEscの文脈を維持する。詳細内のAltアクセスキーは、OCRパネルが表示中で操作可能な場合に詳細を展開して入力欄へ移動する。ガイド閲覧・展開・選択だけでは未保存状態やUndoを変更しない。ガイド下部の閉じるボタンにアイコンは付けない。操作ボタンは承認済みアイコンを再利用し、新しい合成アイコンは作らない。

## 実装境界と性能

対象・状態は現在選択の派生値とする。コマンドの可否を再利用し、UI用の別条件で実行可否を上書きしない。既存の選択・モード・画像準備・ロック更新時に通知する。全ページ走査、画像推定の自動実行、新たなPDFコピー、パネル再構築は行わない。

詳細の折りたたみとガイドは表示だけの機能。設定形式20、プロジェクト形式1.11／最低読込版dev.206を変更しない。複数選択の部分固定は操作対象外件数として示し、全件固定と混同しない。校正で文字訂正可能でも画像調整は不可、という既存区別を維持する。

## 受入検証

- 未選択、単一行、複数行、複数文字、最終文字、部分固定／全固定、画像未準備、校正、読み順の状態と実際のコマンド可否が一致する。
- ガイドON/OFF設定にかかわらずOCRの長文は常設されない。リンクなどの既存説明切替は動作する。安全通知と入力エラーは消えない。
- 文字付き調整ボタンから既存コマンドに到達でき、画像調整・固定・Undo/Redoの既存診断を通過する。
- 詳細内のアクセスキー、日英表示、狭いパネル、浮動パネルを実UIで確認する。閲覧操作でプロジェクトを変更しない。
- Releaseビルド、契約テスト、バージョン診断、関連アプリ診断を実行し、配布用ビルドでも再確認する。

## 後続段階

同倍率の変更前後比較、ページ上の固定端表示、疑わしい候補・確認進捗、印刷番号対応の例示UI、他機能への基本／詳細の展開は今回の実装対象外。ガイド整理を理由に墨消しの情報漏洩警告や保存時検査を削除しない。

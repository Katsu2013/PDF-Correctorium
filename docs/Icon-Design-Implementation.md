## 保守・描画方式

- 形状は `src/PdfCorrectorium.App/Resources/VectorIcons.xaml` に集約。
- dev.207では`ActionIcon`によってメニュー・プロパティボタン・リンクのツールバーに同じ形状を描画。メニューは18px、ツールバーは既存のサイズ設定。UI要素は共有せず、Freezeした形状だけをキャッシュする。
- 合成形状は `BadgeIconGeometryExtension` が辞書読み込み時に一度生成し、Freezeして共有。描画ごとの画像生成・ファイル読み込みはなし。
- 元形状から記号の太い輪郭を減算し、細い記号を加算。白い縁取りを重ねず、本当に透明な隙間を作るため、選択背景にも白が残らない。
- 輪郭線は1.8、記号線は2、抜き用輪郭線は通常8・しおりの－のみ9.5。記号からの透明幅は片側3／3.75設計単位（22pxでは約2.75／3.44px）。確認済み画像の線幅・位置を採用。
- 新形状は固定24×24・ClipToBoundsのCanvas内で描画。合成形状はFillのみを指定し、さらにStrokeを加えない。
- PDFの文字はフォント依存にせずベクター。Material Symbolsから使用した2形状の出典・変更箇所・ライセンスは `licenses/MaterialSymbols` に保存し、次回ビルド時に配布先へコピーする設定を追加。

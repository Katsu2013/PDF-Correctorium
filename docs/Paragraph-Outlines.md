# 段落編集の外枠（dev.264）

2026-10-29。利用者確認により、段落編集では全段落を薄い外枠で表示し、選択中の段落だけ強調する。既存の「OCR枠を表示」と不透明度設定に連動し、PDF出力には含めない。

## 表示・操作

OCR編集の段落編集モードだけに表示する。自動判定・手動指定とも、行のクリックで選択する段落と同じ共通分割を使い、段落全体の外接範囲を囲む。回転した行は回転後の四隅まで含める。空の編集行は単独の枠を表示し、削除済み行は含めない。選択した行を含む段落全体を強調し、複数段落の選択では各段落を別々に強調する。

段落編集では従来の行ごとの枠・塗りを抑え、段落の外枠を主にする。非選択は薄い1px、選択は濃い2px相当とし、ズームに対して線幅と外側余白を画面上で一定に保つ。本文は塗りつぶさない。枠は非操作の描画ガイドで、既存の行クリック・Ctrl選択・キーボード操作を妨げない。通常の行・文字・読み順・校正・リンク・墨消しモードには追加しない。

既存OCR面のネイティブItemsPanel原点へ合わせて描く。ScrollViewer内部の余白はListBox.Paddingと一致するとは限らないため、実原点を参照する。赤文字や行の位置を動かしたり、1px等の固定値をデータ座標へ加えたりしない。

## 性能・保存

現在ページに1個のDrawing要素を置く。段落・文字ごとのWPF要素を作らない。現在ページの行に限って変更を監視し、文字・位置・サイズ・回転・方向・読み順・削除・段落指定の変更時にだけ分割と範囲を無効化する。連続する変更通知は次回描画へまとめ、選択・ズーム・透明度変更では分割と範囲を再利用する。モード変更・非表示・ページ切替時に旧行の購読とキャッシュを解放する。全ページの先読み・OCR・PDFの再描画を追加しない。

文字・枠・ロック・読み順・段落データ・Undo履歴・未保存状態は、表示切替では変更しない。プロジェクト形式1.14／最小読込dev.262、設定21と依存資源を維持する。PDF出力経路から描画層を参照しない。

dev.264では「まとめる」の方向混在・非連続選択の条件を変更しなかった。dev.266では利用者指定のChapter／1に対応し、手動段落の方向混在を許可する。非連続選択は引き続き制限する。[追加仕様](Chapter-Grouping-And-Side-AutoHide.md)。

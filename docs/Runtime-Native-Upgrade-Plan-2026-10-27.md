# ランタイム・ネイティブ依存関係の修正順序

2026-10-27、dev.248で着手。段階ごとに版数・採用資源・診断結果を記録し、最終入力が確定するまで配布物を認証しない。

1. **校正診断を.NET 8で修復**：画面のLoaded処理と専用設定保存先を用意し、従来の69項目を維持する。
2. **PDFium単独更新**：最初の158.0.8111の試験後、公式インデックスで新公開を確認した158.0.8125を最終候補とし、ハッシュ・API・同梱通知、文字抽出・描画・リンク・墨消し・出力を確認する。
3. **qpdf単独更新と組合せ確認**：12.4.2のWindows x64 MSVC一式とライセンスを照合し、JSON/QDF処理・墨消し残留・隔離を確認する。
4. **.NET 10移行**：7プロジェクトを変更し、CA2022を修正。TFMで切り替わるDLL・日本語資源のロックを更新し、実ランタイムとワーカーを確認する。
5. **配布と文書の仕上げ**：環境要件、現在の設計・利用案内、版管理のRuntime検査を更新し、全診断と新しいBuildPortable出力の照合を完了する。

任意の過去文書・特殊ハードウェアを検証済みとはしない。未確認の条件、途中の失敗、外部環境による障害は最終記録で区別する。Gitの履歴変更やGitHub公開はこの作業に含めない。

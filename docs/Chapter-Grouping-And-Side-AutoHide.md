# 混在方向の手動段落と左右別の収納（dev.266）

2026-10-29。利用者の「Chapter」と縦書きの「1」を同じ段落にしたいという指定、および「格納だけ一括、固定へ戻すのは個別」という確認に基づく。

## 手動の段落指定

dev.270補足：表示済みページから読み上げ用のスナップショットを作る際も、段落編集・保存と同じ「削除済みを含まない現在の読み順」を使用する。削除済みの旧OCR項目は編集履歴用に保持され、欠けた読み順の代替値が有効項目と重なる場合がある。その項目を読み順へ戻して誤った区切りを作らない。保存済みの段落IDは書き換えず、まとめ直しを要求しない。読み上げ対象外の有効行、墨消し、不正な枠、部分選択の保護境界は維持する。

読み順が連続する2項目以上では、横書き・縦書きと読み進む方向が混在していても「まとめる」を利用できる。「行ごと」にした後も再びまとめられる。項目の文字方向・位置・サイズ・文字送り・修正済み文字・ロックは保持し、ParagraphGroupIdだけを設定する。通常の自動判定は引き続き方向の違いで区切る。

明示段落を、段落編集・外枠・読み上げで共通に扱う。Chapterと1は同じ枠・選択範囲とし、読み上げは「Chapter 1」とする。削除・墨消し・読み上げ対象外・部分的な文字選択の境界は引き続き優先し、手動指定で保護対象を巻き込まない。非連続の選択をまとめて読み順を変える機能は追加しない。

ボタンの無効理由は無効中も表示できるツールチップで示す。プロパティに常設の説明文を追加しない。Undo／Redo、保存・再読込で指定を保持する。既存のデータ形式1.14／最小読込dev.262を維持する。

## 左右別の自動収納

標準ピン・コンテキストメニュー・表示メニューのどこからでも、収納は同じ側の表示中パネルをまとめて行う。左と右は独立する。同じタブグループか、別々の上下分割かで動作を変えない。ページ・しおり・OCR／リンク／墨消し／コメントのプロパティ・読み上げを対象とし、ツールバーとPDF編集領域を含めない。浮動パネルを勝手にドッキングしない。ライブラリのタブ・ダブルクリック固定は既定の無効を維持し、有効化された場合だけ同じ個別固定へ接続する。

固定へ戻す場合は、選んだパネルだけを固定する。他のパネルはアイコンのまま残し、同じ側の収納設定自体も保持する。後から読み上げ等を開くとその側の収納設定に従い、既に固定したパネルを勝手に収納し直さない。もう一度その側の一括収納を選んだ場合は、個別固定も解除して同じ側をすべて収納する。表示メニューの表記も「このパネルを固定／同じ側をまとめて収納」とする。

固定したパネルを反対側へ移動した場合、個別固定も移動先へ引き継ぐ。移動直後に一括収納した場合も現在の配置で判定し、移動前の固定情報を残して収納を妨げない。

×で隠したパネルは勝手に表示しない。後から表示したパネルを収納タブに追加する際は、ネイティブのタブ生成後に内容を開く。収納・固定・再表示でも同じビュー・再生器を使い、再生位置・一時停止を保持する。幅継承・狭い旧幅の補正・32pxのアイコン付きタブを維持する。

## 保存・保守

左右の収納状態と個別固定の例外は、アプリ設定内の既存ネイティブレイアウトXMLに任意属性として保存する。全パネルを×で隠した後の再起動でも収納設定を失わない。固定例外には既知の7パネルだけを認め、重複・不正な値・ツールバー等を拒否する。属性のない旧レイアウトは既存の収納タブから左右の状態を補い、同じ側へ統一する。設定形式21と依存ライブラリは変更しない。

パネル数は7個に限り、親や表示状態の変更を落ち着いたタイミングへまとめて処理する。PDF・OCRの読込みや全ページ走査を増やさない。ネイティブコマンドの実行可否を共用し、固定操作だけを対象パネルへ適用する。タブ生成の非同期タイミングを扱い、ビューは作り直さない。

実際のボタン・標準ピン・後から開く読み上げ・同一グループと別グループ・個別固定・×・レイアウト復元・再起動を検証する。結果と配布先は[リリースノート](releases/v1.0.0-dev.266.md)へ記録する。

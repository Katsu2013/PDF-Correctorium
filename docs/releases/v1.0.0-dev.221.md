## 保証範囲と残条件

既存の文書全体の構造ツリーを除去するため、タグ・代替テキストによるアクセシビリティは失われます。範囲外の別ページ・しおり・文書情報・添付に複製された全ての意味的な秘密の自動除去を保証しません。プロジェクトは原本・編集前情報を保持します。詳細は [セキュリティ設計](../SECURITY-DESIGN.md) と [受付方針](../../SECURITY.md) を参照してください。

AppContainerは文書処理の境界を強化しますが、OS／管理者や既に同一ユーザー権限で実行中の攻撃者の侵害を防ぐものではありません。隔離用に対象PDFとランタイムをコピーするため、開始時間と一時ディスク使用量が増えます。異常終了時の一時データ残存や暗号消去は保証しません。実際の外部SMB認証送信やOOMを起こす試験は実施していません。

コード署名、依存関係の最新アドバイザリー確認、独立したセキュリティレビュー、非公開の受付窓口と修正版の配布手順の確認が正式公開前に残ります。今回の成果物を正式版と認定していません。build-info.jsonは既存GitコミットとgitDirty=trueを記録しています。修正は未コミットであり、commit・push・タグ作成・外部公開は行っていません。

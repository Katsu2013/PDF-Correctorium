# v1.0.0-dev.211：ダイアログ下部のボタンを文字のみへ統一

## 変更内容

利用者の指示に合わせ、ダイアログ下部の操作列のアイコンを除去した。OK・適用・既定値に戻す・保存・実行・取消・中止だけでなく、同じ列の前後移動・全選択／解除・出力先への移動も文字のみとする。20画面の28配置を変更し、元から文字のみの注意事項画面も含む全21 XAMLダイアログ／47下部ボタンを検査する。

内容領域内の検索・置換・新規・削除、メニュー、右クリック、プロパティ、ツールバーのアイコンは維持する。ラベル、イベント処理、アクセスキー、Tab順、Enter／Escの役割は変更していない。OS標準のファイル選択・確認ダイアログは変更していない。

配置を区別する安定した `DialogFooter` 名を付与した。翻訳されたラベルからの推測や、実行時にアイコンを走査して消す仕組みは追加しない。追加処理は診断時のみで、通常のPDF読込・編集・出力に負荷を追加しない。

## 設計と検査の更新

正式なアイコン基準・画面仕様・テスト戦略と現在のREADME／実装状況を更新した。下部ボタンの除外は同一操作のアイコン統一より優先する。dev.209／210の配置数・検証結果は当時の履歴として維持し、現在の意図的除外を追加漏れとは扱わない。

静的配置検査は全ダイアログを列挙し、下部のアイコン再混入、下部領域の登録漏れ、通常取消ボタンの配置を確認する。dev.210の74登録対象のうち20件を下部除外へ再分類し、残る54件と動的リセットのアイコンを継続検査する。日英の実画面診断と一括処理画面診断にも下部アイコン不在の確認を追加した。

プロジェクト形式1.11／最低読込版dev.206／設定形式19は変更なし。前回監査の無効時の薄さ、OCR編集・墨消しアイコンのサイズ追従、英語の動的メニュー等は別件であり、今回解消したとはしていない。

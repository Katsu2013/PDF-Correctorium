# v1.0.0-dev.267 — 読み方のPDF保存と出力処理の軽量化

2026-10-29。

共通辞書・行ごとの例外を、文字を編集していない行も含めて出力PDFの読み上げ用代替テキストへ保存します。かなを本文へ置換せず、確認用ルビも描画しません。保存後のPDFから読み方を再取得できたことを確認してから保存先へ確定します。縦書きと、複数の文字オブジェクトに分かれた行にも対応します。

墨消しと交差する行の読み方は保存しません。既存の構造から消去済みの内容を持ち越さず、範囲外の文字・読み方だけを再構築します。安全に既存タグとの対応を決められない場合は、本文やタグを破壊する代わりに理由を表示して中止します。

変更のない既存リンクのページ別再確認、無変更な非暗号化PDFの初回再保存、対象のない文字校正用再読込を省きます。出力の分離実行、墨消し・検証・保存先の競合対策を維持します。

読み方のAlt情報を音声に使うかはリーダーの対応によります。PDF内部の保存確認と、利用リーダーでの実音声確認を区別します。検索・コピーをかなへ変える互換モードは追加していません。

形式1.14／最小読込dev.262、設定21、依存ライブラリは維持します。[設計](../Pdf-Reading-Export.md)。

# v1.0.0-dev.243 — 資料別の共通OCR補正辞書

2026-10-25。製品版`1.0.0-dev.243`、数値版`1.0.0.243`。GitHub公開版の更新ではない。

## 変更

- 「OCR → 資料のOCR辞書...」と類似語画面から、正解語・訂正ルール・無視語を管理する。頻出語は別の参照タブで表示し、正解と混同しない。英数字用語と明示登録した日本語語句に対応する。日本語の自動形態素抽出、モデル再学習、アプリ共通への蓄積や外部送信はしない。
- 類似語の選択修正時と再OCR確認時に、任意の正解語／ルール登録を行える。新規ルールの自動許可はオフ。文字と任意登録を1回のUndoで戻し、辞書だけの変更もUndo・通常保存・復旧に含める。既存の並べ替え、差分表示、部分修正後の残り候補、ロックを保持する。
- 再OCRの生結果を変更せず辞書へ照会し、候補と理由を表示する。「認識結果に戻す」は生の結果に戻る。最終文字列で既存画像から文字幅を調整する。頻度・類似度では自動適用しない。明示許可済み・同Unicode文字数・完全一致・一意・非循環・非重複・非固定のルールだけを利用者の再OCR操作時に自動適用する。元の文字から生OCRまでに未確認の置換／削除がある場合は、ルールがあっても確認を省略しない。
- 語彙は入力・描画・保存・OCRより低い優先度で背景準備する。保存OCR、付随テキスト、隔離PDFワーカーの文字のみ抽出を利用し、辞書のために全ページ画像やOverlayViewModelを生成しない。集計済み寄与を差し替え、配置変更や固定操作では再集計しない。進捗は下部ステータスバーで表示する。
- プロジェクト形式1.12に正本の`ocrLexicon`を追加し、辞書を失う旧アプリでの保存を避けるため最小読込版をdev.243とする。旧形式1.0～1.11を読む。完成した頻度だけを任意の`cache/ocr-word-counts.json`に保存する。キャッシュ破損・不一致は再生成、正本破損はエラー。ZIP安全上限は維持する。

## 制約

- 日本語は登録語句のみ。英数字の頻度集計は従来の技術用語抽出規則に従う。日本語の頻度を自動分かち書きして登録しない。
- 自動登録・自動学習はない。頻度は資料に誤りが多い場合の正しさを保証しない。
- 性能測定はOCR推論やモデル精度とは別。合成資料での測定値を実書籍全般の速度・精度保証とはしない。
- 辞書・頻度キャッシュは墨消し対象の語を含み得る作業データであり、配布PDFには含めない。

# v1.0.0-dev.252 — テーマとWindows標準音声の読み上げ

2026-10-27。中間候補。Release、契約63件、テーマ／音声74項目、キーボード3,593項目等のソース診断と、自己完結型ZIP／MSIXの生成まで実施。公開物の通し試験中に、墨消し除外は移動前の座標・元領域との対応も保持すべきと見直したため、残りのdev.252通し試験を意図的に停止し、[dev.253](v1.0.0-dev.253.md)へ進めた。履歴・成果物は保持する。本候補を最終版として扱わない。

- 設定の表示タブにライト／ダーク／Windowsに合わせるテーマを追加。アプリ全体へ保存し、実行中のOS通知で自動変更する。既存の操作寸法・ドッキング配置を保ち、PDF紙面・出力色・表示倍率を変えない。
- メニュー「表示 → 読み上げ」からモデルレスの操作画面を開く。選択したOCR文字・行・段落、現在ページ、現在ページから最後までの3範囲を選択できる。
- 再生、一時停止・再開、停止、導入済み音声と速度の選択を提供。Windowsの標準音声合成を使用し、音声モデルを同梱・導入しない。音声と速度はアプリ全体で保存し、文書を未保存扱いにしない。
- 修正後のOCRと明示的な読み仮名・読み順・読み上げ参加属性を利用。元PDFとの二重読みを避け、削除済み文字を復活させない。墨消し範囲と交差する行は保守的に読み上げから除外する。
- OCRが未読込のページは、必要時に隔離ワーカーで文字と座標だけを取得。読み上げのために全ページを描画したり、画像だけのページへ勝手にOCRを実行したりしない。
- 読み上げ中の行は独立した一時マーカーで表示し、通常のOCR枠の表示設定や文字選択と分離する。本文変更・文書切替・ページ構成変更は古い再生を取消し、位置・サイズだけの調整では安定した領域IDで追従する。
- 公式System.Speech 10.0.14（MIT）をNuGetのSHA-512と照合し、実DLL・ライセンスをロック。通常の起動時には音声列挙・エンジンを初期化しない。

プロジェクト形式1.12／最小読込dev.243／設定21は維持する。追加した設定は省略可能で、旧設定の未指定値には既定値を使う。読み上げは音声ファイルの書き出し機能やナレーターの全音声への対応を意味しない。関連付けが未実装のルビを本文の一部分へ推測適用しない。

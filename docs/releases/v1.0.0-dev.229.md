# v1.0.0-dev.229 — 類似語候補一覧の並べ替え・可読性

## 変更点

- 差分強調のためにテンプレート列へ変更した際、並べ替えの参照先が未指定だった「現在の語」「修正候補」にSortMemberPathを設定。列見出しクリックによる標準の昇順／降順並べ替えを復旧しました。並べ替える値は強調装飾ではなく元の文字列です。
- この2列のセル文字だけ16 DIPへ拡大し、初期幅を115から140 DIPに調整。見出し・ページ・件数・理由・前後の文章などは拡大しません。長い語は省略表示し、ツールチップ・コピーには全文を維持します。
- 赤・太字・下線の相違箇所表示、選択した候補への移動、部分修正と一覧保持を維持します。既存のWPF並べ替えを利用し、解析処理を再実行したり独自ソートを追加したりしません。プロジェクト／設定の互換性・PDF出力は変更しません。

### 試作中の失敗と採用判断

- 診断コードのコンパイルエラー2件を修正し、最終ビルドは警告／エラー0です。
- 削除共有の追加だけでは読取中の上書き移動が失敗することを確認しました。`File.Replace`を使う試作は通常プロセスでは保持ハンドル試験を通りましたが、隔離ワーカーでは起動準備段階で停止し、不採用としました。隔離権限やACLを緩めて通す変更はしていません。
- 試作の直接読取テストは更新瞬間の共有違反で失敗したため、並列ポーリングは実アプリの`TryReadStateAsync`を使用し、一時的な読取不可を飛ばした後に完全なJSONを再取得できることを検査します。恒久的な読取不能を成功扱いしない検査も保持しています。
- 中間失敗記録は`outputs/verification-dev223-export-state-source`、`...-source-final`、`...-source-v2`、`...-source-v3`および`outputs/verification-dev223-security-source`に残しています。今回配布したのは、期限付き再試行・短時間読取方式の最終成功ビルドです。

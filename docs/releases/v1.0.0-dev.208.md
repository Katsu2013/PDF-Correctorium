# v1.0.0-dev.208：説明表示とプロパティ操作の共通化

## 修正内容

- OCR・読み順・校正確認・墨消し・リンク編集の操作説明を共通の表示スタイルへ統一。従来の11か所と、表示切り替えのなかった8か所の計19か所を「説明」と設定画面の同じ設定で制御します。墨消しの説明枠は枠ごと閉じ、空の囲みや余白を残しません。
- 状態表示（タイトル、選択件数、リンク先、利用者の入力したリンク説明）、PDFの注意事項、読み込み状況、検証エラーは説明設定で隠しません。未選択時の短い案内も残します。
- リンクの整列9種類はOCRと同じ32pxのボタン、24pxのベクターアイコン、ツールチップ・アクセシビリティ名を使用。サイズ関連／左右整列／上下整列の3行に揃えました。複雑な合成アイコンは追加していません。
- リンクロックはOCR同様に小型アイコン＋ラベルと押下背景で表示。リンク先編集を許可しつつ、移動・サイズ変更・整列・削除を禁止する既存仕様を維持します。
- OCR関連の文書注釈とリンク編集で共通する6操作を、編集・追加／移動先・削除／戻る・進むの2列配置へ統一。独自の整列アルゴリズムを共有化して挙動を変えることはしていません。
- キーボード回帰で新しい注釈ボタンと既存メニューのAltキー競合を検出して是正。OCR関連の注釈はメニュー操作を維持し、リンクモードはK/N/G/D/J/R/L/Uを使用。整列のツールチップ等の英語表示も追加しました。

## 維持する仕様・互換性

- リンク整列は最初に選択した矩形が基準です。OCR位置整列は選択全体の外接範囲、OCR幅・高さは指定した基準領域に従います。OCR位置ロックは削除を禁止しませんが、リンクロックは削除も禁止します。
- 複数行・OCR領域追従・未対応動作のリンクを無理に整列しません。Undo、PDF読込／出力、墨消しの処理内容は変更していません。
- プロジェクト形式1.11、最低読込版dev.206、設定形式19のままです。保存manifestのapplicationVersionは実行版に追随します。
- 元フォルダで作業し、別フォルダへのソース移動、Git再初期化、コミット、push、GitHubリリース公開は行っていません。

# v1.0.0-dev.226 — 類似語分析の5件の改善

2026-10-15。[採用設計・制約](../Similar-Words-UX-dev226.md)に基づき実装。データ形式1.11／最低読込dev.206／設定20は維持し、原PDFは変更しない。

- 共通ProgressBarの必須部品PART_Trackを復元。値だけでなく実表示幅の増加を検査する。収集中もDispatcherへ描画機会を渡す。分析用入力PDFは処理単位でステージする。
- 選択した修正候補の適用後、未修正・固定済み候補を残す。同じ領域の後続候補は文字数差からUTF-16位置を更新し、原文一致・非重複を再検査。頻度は分析時の値と明示する。1回のUndoで1バッチを復元。Undo／Redoや外部編集・再読込後は古い候補を適用しない。
- 英数字技術用語に隣接する未対応の`」`を語に残し、j／JとのOCR混同として評価。正しい対の閉じ括弧や単独の括弧は除外する。認識保証や日本語括弧の自動置換ではない。
- 現在語・修正候補の差分を赤字＋太字＋下線で表示。多対一や挿入・削除も両列で見比べられ、文字列・コピー値は保持する。64文字以内の有界比較を表示セルに適用。
- 検索・分析で未訪問ページに作った96px座標のモデルを、通常表示で無変換に再利用していた問題を修正。共有の描画寸法計算を用い、生成時から通常表示座標でOCRモデルを保持。小さな画像はそのまま破棄し、大画像の全ページ保持や履歴モデルの後付け置換を行わない。

通常の読込メッセージのステータスバー移動は本更新の対象外。Git commit／push／tag・GitHub公開・署名・独立レビューは実施しない。

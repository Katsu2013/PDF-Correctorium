# v1.0.0-dev.231 — 選択行再認識の句読点余白

## 変更

- 選択行の左右は行高の半分（4〜96px）、上下は行高の12%（2〜12px）まで原PDFの画素を含める。単に切り出し後の白余白を増やすのではなく、行枠の外側の句読点を入力へ取り込む。回転行では行の軸に沿って余白を付ける。
- 濃い画素の外接範囲を求める際、離れた句読点も保持し、文字画像の高さに応じた2〜8pxの白余白を付ける。大きな白い末尾をそのままモデルへ渡さない対策は維持する。
- 既存文字の削除・置換を自動適用しない規則、ロック・Undo・元文字保持・隔離・キャッシュ上限は変更しない。認識モデルの性質による句読点の誤読をすべて解決する保証ではない。
- ページの一部／ページ全体／PDF全体への新規OCRは別の拡張。既存OCRの扱いと文字方向を確認中であり、この版には含めない。

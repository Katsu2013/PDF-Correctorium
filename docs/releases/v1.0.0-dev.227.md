# v1.0.0-dev.227 — 読み込み進捗とOCR枠表示

## 変更点

- 通常のリンク確認・PDF特性確認のメッセージを、上部通知から下部ステータスバーへ移動。ページ件数と小さな進捗バーを表示し、詳細はツールチップから確認できます。失敗時の編集停止理由と入力PDFの注意事項は引き続き上部に表示します。
- 「表示 → OCR枠を表示」を追加。枠・塗り・操作ハンドルを隠し、赤いOCR文字だけを表示したまま選択・編集できます。
- アプリ設定の表示タブに、OCR枠の表示チェックと不透明度調整・プレビューを追加。初期値は既存描画の45%で、文字自体の不透明度とは独立です。設定はアプリ全体で保存し、設定移出入にも含まれます。
- 表示変更のためのPDF再読込や全ページ走査は行いません。プロジェクトの未保存状態・Undo・PDF出力を変えません。設定形式21、プロジェクトの互換形式は据え置きです。

詳細仕様: [OCR表示と読み込み進捗](../OCR-Overlay-Display.md)

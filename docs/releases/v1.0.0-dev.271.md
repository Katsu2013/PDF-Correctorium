2026-10-30。現行ソースの準備版。ユーザーの「ビルド前に確認」に従い、この段階ではアプリの再ビルド・新しい配布物の認証・公開を行っていない。

## 方針の維持と説明

文書処理は完全ローカルとし、PDF・OCR本文を外部へアップロードしない。利用者が実行するWebリンクと更新確認は許可する方針を確認済み。課金による回数・期限制限を追加せず、従来の入力／資源制限を残す。墨消しの本文除去・出力検査を弱めない。[具体例と既定上限](../Local-Processing-And-Redaction-Scope.md)。

## ソースに反映した変更

- BuildPortableのbuild-infoをschema 2にし、配布ファイル全件の相対パス・長さ・SHA-256を記録する。旧版の部分記録を利用済みフォルダーから後付けで認証し直さない。
- 新しいNewReleaseStageは、認証時の一覧にあるファイルだけを別フォルダーへコピーする。元フォルダーの設定・キャッシュ・PDFは削除せず、公開用資源へ混ぜない。未記録ファイル、改変、欠落、再解析ポイント、危険なパス、文書・秘密鍵等の混入を検査する。
- ZIPを一覧から作成し、完成アーカイブの全エントリ・サイズ・ハッシュを確認する。Windows PowerShell 5.1でもエントリ名をスラッシュへ統一する。
- 公開判定へ完全な配布内容とクリーンなGit出所を追加。依存関係レビューは名前だけでなくロックされた実バージョンにも照合する。
- 出力用の `output/` とロックから復元できる未追跡NuGetアーカイブをGitの除外対象へ追加する。利用者や既存ファイル、追跡済みの旧アーカイブは削除しない。
- 単独診断2プロジェクトのWindows APIターゲットと投影パックをアプリへ揃え、全7プロジェクトをソリューションに含める。通常のReleaseビルドから取り残さない。
- テストソースとCI定義もビルド入力指紋へ含め、Ordinal順にしてPowerShell 5.1／7の並べ替え差をなくす。以前の指紋・認証済みフォルダーは変更しない。
- WindowsのCI定義と一連の検証スクリプトを追加。依存関係復元、Release、契約、隔離・不正入力・墨消し残存、保存・履歴、テーマ／読み上げ、画面、版管理、配布物照合を同じ現行版で行う。署名・GitHub Release作成・Store提出は行わず、公開承認とは区別する。
- README、Webサイト、FAQ、セキュリティ設計で、ローカル処理・回数制限・墨消し対象と編集データの区別を揃える。

プロジェクト形式1.14／最小読取版dev.262、設定21、ランタイム10.0.14、依存ライブラリー、文書処理の実行経路は変更しない。アプリ起動時へ配布検査や全件ハッシュ処理を追加しない。

# v1.0.0-dev.213 — 機能別プロパティパネル

## 変更内容

- プロパティを「OCR・校正」「リンク」「墨消し」「コメント・タグ」の4枚に分割。既定は右側タブ。AvalonDockのタブドラッグ、左右配置、上下分割、浮動・再ドッキングを使用する。
- 編集モードを変更すると対応するパネルを選択する。パネルを見るだけでは編集モードを変更せず、配置も移動しない。別モードのパネルには明示的な編集モード切替ボタンを用意する。
- OCR上に常時表示していたリンク操作6個を除き、「選択文字にリンクを設定」の短い入口にする。リンクの詳細編集・一覧・整列・ロックはリンクパネルへまとめる。
- コメント・タグは現在の文書／ページ／OCR選択対象を示し、本文と付与タグを一覧表示。変更は既存の確認ダイアログを使い、共通のUndoと保存を維持する。タブを見るための全ページ同期は行わない。
- 説明ON/OFFは全パネル共通。読込案内と入力PDFの警告はタブ外の共通領域へ移し、非選択タブの裏に隠さない。
- 「表示 → 機能別プロパティ」で各パネルの表示・非表示。「表示 → 標準配置に戻す」で既定へ戻す。F6の領域移動に各プロパティを含める。
- パネルを並べた際のツールバーとのキー競合を除去。リンク枠固定はAlt+X（fiX）、範囲追加はAlt+W（neW）、戻るはAlt+R（Return）、進むはAlt+T（nexT）。編集モードの共通入口は従来どおりAlt+M。リンク／墨消しの編集部品は対応モードでのみ有効とし、閲覧とモード変更を分離する。
- 浮動ツールバーの元の空行は除去しつつ、戻り先を直前のドッキング辺で扱う。[AvalonDockの標準LayoutUpdateStrategy](https://github.com/Dirkster99/AvalonDock/blob/v4.74.1/source/Components/AvalonDock/Layout/LayoutAnchorable.cs)を利用し、アクティブなプロパティパネルへ勝手に混ざることを防ぐ。上下左右のガイドによる明示配置は変更しない。
- 設定形式20の`WorkspaceLayoutXml`と配置プリセットへ、タブ・分割・浮動位置・非表示を含む実際のレイアウトを保存。最大65,536文字、既知9個のContentIdのみ、DTD・外部実体は禁止。不正設定は既存の配置情報へフォールバック。従来設定は移行可能。
- プロジェクト形式1.11／最低読込版dev.206は変更しない。編集モデル・既存リンクの背景読込・PDF出力を別実装にしない。承認済みアイコンとダイアログ下部のアイコン除外も維持する。

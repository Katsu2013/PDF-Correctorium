# v1.0.0-dev.247 — 編集単位の大中小順と説明重複の整理

2026-10-26。製品版`1.0.0-dev.247`、数値版`1.0.0.247`。GitHub公開ではない。

## 変更内容

- ツールバーの編集単位を「段落編集 → 行編集 → 文字編集」の大・中・小順にする。表示位置ではなく、各項目のTagに持つOcrEditUnit値で双方向に対応付ける。既存のLine=0／Paragraph=1／Character=2は変えず、初期値の行編集は新しい表示位置でも維持する。校正モードへの切替で行編集になる従来仕様も維持する。
- 「行全体」「選択文字以降」が同じ理由で使用不可の場合、その理由は1回だけ表示する。2つが利用可能な場合はそれぞれの範囲、末尾文字など片方だけの制約は個別に表示する。1文字しかない行と全行の位置固定は、曖昧な共通文言ではなくそれぞれの理由を表示する。コマンドの実行条件そのものは変えない。
- OCR未選択は上部の現在対象で示し、下部の同じ未選択案内を削除する。現在ページ・モード・ロックの情報は残す。ヘルプOFFでも必要な状態説明は残る。
- 一般ステータスと処理進捗が同じ文章の場合、表示だけを進捗側へ集約する。PDF出力中は既存の操作停止オーバーレイに進捗を集約する。異なるステータスや警告は一律に隠さず、処理終了後は通常のステータス表示へ戻す。StatusMessageそのものを消去せず、保存やOCR処理・進捗率・世代管理・キャンセル規則は変更しない。
- 安全上の全体通知とプロパティ内の注意一覧、リンクの一覧と詳細など、別の役割を持つ再掲は今回一括削除しない。

選択と処理状態から表示を派生させるだけで、文書走査・画像解析・再OCR・追加のPDF描画を行わない。プロジェクト形式1.12／最小読込版dev.243／設定形式21と依存ライブラリは変更なし。

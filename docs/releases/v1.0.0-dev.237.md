# v1.0.0-dev.237 — 文字種と枠の比率による外れ値検出

2026-10-23。製品版`1.0.0-dev.237`、数値版`1.0.0.237`。GitHub公開版の更新ではない。

## 変更

- 同程度の枠の生の文字数中央値を比較する方式から、文字種補正後の文字密度を比較する方式へ変更。CJK・欧文・半角カナ・狭い／広い欧文字・空白・Unicodeテキスト要素を考慮する。
- 枠の縦横比で正規化し、同じ書字方向・近い行の太さから基準を求める。文字種に応じた対象行自身の目安を表示し、健康なCJKを欧文の文字数へ合わせない。
- 安定した独立基準が不足する場合や基準が大きくばらつく場合は判定しない。極端な密度を基準作成から外し、改行を含む複数行枠は単一行モデルで扱わない。2文字以上の差という保守的条件は維持する。
- UIの条件を「行の太さ許容差」「密度比の閾値」へ合わせ、「標準文字数」を「目安文字数」に変更。「密度比」を追加し、ソート・固定済みの表示切替・ジャンプは維持。
- 総当たり比較をスライディング窓と順位統計へ置き換え、概ねO(文字量+n log n)、O(n)保持へ改善。比較計算をバックグラウンド化し、キャンセルに対応。PDFの追加描画・再OCR・モデル読込は増やさない。
- 元PDF・プロジェクトを自動変更しない。互換形式・設定形式・依存資源に変更なし。[判定仕様と制約](../OCR-Character-Density.md)。

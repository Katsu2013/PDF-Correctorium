# v1.0.0-dev.216 — OCRプロパティの基本／詳細整理

承認済み操作改善案の第1段階。設計原本は[OCRプロパティ改善設計](../UX-Ocr-Properties-dev216.md)。

- PDFページ・OCR選択数・主選択行の文字数と、領域／文字の固定状態を短く表示する。
- 画像調整を「選択行全体」「選択文字以降」の文字付きボタンへ整理する。作用範囲、対象外の行、最終文字、画像未準備、校正モードなどの条件を隣接表示する。
- 読み方・座標・寸法・回転を折りたたみ詳細へ移す。既存のAltアクセスキーで展開して入力欄へ移動できる。領域固定は基本側に残す。領域削除は内容の後に置く。
- OCRの長い説明は操作ガイドへ移す。他パネルの説明ON/OFFは維持する。入力エラー、読込進捗、PDF安全通知は常時残す。
- 既存のコマンド・推定器・文字／領域固定・単一Undo／Redo、パネルIDと配置復元を維持する。選択変更で推定を実行せず、全ページ走査やPDFコピーは追加しない。

プロジェクト形式1.11／最低読込版dev.206、設定形式20は変更しない。設計Markdown原本を更新した。変更前後比較・新規固定端オーバーレイ・確認進捗と他パネルの詳細整理は後続段階であり、実装済みとは扱わない。Gitコミット・push・公開は今回の作業に含まない。

# v1.0.0-dev.232 — 再OCR後の文字サイズ自動調整

## 内容

- 選択行の再認識結果を適用する際、既存の画像ベース文字送り推定を使い、行全体の文字幅・境界・必要な行端調整も適用する。認識した文字列が既存文字列と一致した場合も調整する。
- 再OCRに使った300dpiの行画像と元行の画像内座標を再利用する。文字認識に追加した左右余白も調整対象へ含め、枠外で見つかった句読点を圧縮して元の枠内へ押し込まない。ページ画像の追加描画・全ページ走査・新しい永続キャッシュは行わない。
- 推定は一時モデルでバックグラウンド実行し、自動補完または確認後の適用まで実際の行を変更しない。文字変更と画像調整を1スナップショット・1回のUndo/Redoとして記録する。回転・高さ・読み順・元のOCR情報を維持する。行全体を調整するため、再認識前の個別文字幅は新しい推定値へ置き換わり得る。
- 固定された行・文字、処理待ち中に変更された対象、別文書の古い結果は適用しない。通常の文字調整と同じ推定設定を使う。
- 1文字、白紙、低コントラスト、過密な行などで画像推定ができない場合は、認識文字を破棄せず、元の行範囲へ配分した文字幅を残し、ステータスバーに調整できなかった旨を表示する。低信頼な画像調整も境界の確認を促す。
- プロジェクト1.11／最小アプリdev.206、設定21、OCRモデルと外部依存は変更しない。範囲・ページ・PDF全体への新規OCR追加は、前回の確認待ちであり今回に含めない。

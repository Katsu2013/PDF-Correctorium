## 実装

[dev.243の共通OCR辞書](v1.0.0-dev.243.md)を最終確認した版。OCRメニューの「資料のOCR辞書...」から正解語・明示ルール・無視語を管理し、類似語修正と再OCRで共用する。語彙は背景で準備し、頻度だけで自動訂正しない。再OCRの生結果を保持し、許可済みの同文字数・完全一致・一意な明示ルールだけを自動適用する。確認・手修正後は同じ画像からサイズ調整する。文字・配置・任意登録を1回のUndoへまとめる。

dev.243配布試験後、登録語句・明示ルールに対する未集計の頻度を0件と表示する問題を修正した。未集計は空欄とし、実際に集計した件数は引き続き数値で並べ替えられる。認証済みのdev.243とソースが変わるため、規定どおりリビジョンを更新した。

新規保存形式は1.12、最小読込版は辞書対応の初版dev.243、設定は21。旧形式1.0～1.11を読める。新形式を旧アプリへ戻す前提では使わず、既存バックアップを保管する。学習画像・全出現位置・全本文を辞書へ複製せず、外部送信・モデル再学習・資料間の自動共有はしない。辞書と任意頻度キャッシュは墨消し対象の語を含み得る作業データで、PDFへは出力しない。

### 性能と保存容量

同一Windows x64環境のRelease契約試験。1行照会は準備後100回の平均で、OCR推論・PDF読込／描画・画像フィットは含まない。

| 合成データ | 集計・索引準備 | 準備後の1行照会 |
| --- | ---: | ---: |
| 10ページ×40行 | 2.4ms | 0.035ms |
| 100ページ×40行 | 15.5ms | 0.026ms |
| 450ページ×40行 | 135.3ms | 0.027ms |
| 異なり英数字25,000語 | 297.9ms | 0.038ms |
| 登録日本語2,000語句 | 33.1ms | 1.292ms |

暫定の準備後50ms目標はこの試験条件で満たした。実450ページPDF全体の起動時間・背景CPU・ピークメモリや、文書一般のOCR精度を測定したものではない。元データのない画像ページへ自動OCRを行わない。英数字頻度は従来の技術用語抽出規則（3～64文字、英字2文字以上）に従い、日本語は登録語句との照合。自動形態素抽出・日本語全文の自動辞書化は後段のまま。

2ページの保存診断例ではプロジェクトが1,998→2,596バイトとなった（本文訂正・辞書・日時等の変更も含む）。頻度キャッシュ単体は展開359／圧縮172バイト。容量は語彙数・本文に依存し、この例を大きい資料の増加量保証とはしない。

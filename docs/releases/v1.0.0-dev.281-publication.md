# PDF Correctorium v1.0.0-dev.281（開発版）

[前回公開版dev.274](https://github.com/Katsu2013/PDF-Correctorium/releases/tag/v1.0.0-dev.274)からの更新です。アプリの編集機能はそのままに、公開文書・配布の出所・CI検証を整えました。[dev.199以降の累積機能](v1.0.0-dev.274.md)も引き続き含みます。

## 入手と起動

- リリース添付の`PdfCorrectorium-v1.0.0-dev.281-win-x64.zip`を展開し、`PdfCorrectorium.exe`を起動します。
- Windows x64向けの自己完結型ZIPです。.NET 10.0.14を同梱し、別途.NET Runtimeを導入する必要はありません。
- 未署名の開発版です。ZIPの更新は手動で、MSIX・Microsoft Storeでの配布は今回含みません。

## dev.274からの変更

- 設計PDFのMermaidコードを実際の図へ変換し、コード部分には背景・輪郭・余白を付けました。概要、箇条書き、表、図を増やし、旧資料はarchiveへ整理しました。
- 操作ガイドのWikiを同期し、古い版への直接リンク、未公開Webサイトへの案内、個人環境の絶対パスを整理しました。
- 自己完結型ビルドの.NETランタイム解決を修正。CIでRelease全7プロジェクト、契約テスト、隔離処理、アプリ診断21グループ、完成ZIPを検証しました。
- 製品版番号・実行ファイル版を一元化し、CIだけGitハッシュが版番号に付く差を解消しました。ビルドのGit出所と全配布ファイルのハッシュを記録します。
- 開発者用の診断コマンドは、環境変数で明示的に有効化した場合だけ実行します。通常のPDF処理に必要な隔離ワーカーはそのまま動作します。
- 読み上げの再生失敗時に、空のエラーではなくWindowsのエラー種別・HRESULTを記録するようにしました。

## 検証と出所

- [成功したGitHub CI](https://github.com/Katsu2013/PDF-Correctorium/actions/runs/41333224499)の成果物を再ビルドせず使用します。ビルド元はクリーンなコミット`0b1e84f71b7b765fbfe576f71701b4ce8c590cfb`です。
- 契約76件、安全性125件、監査29件、版管理34件と、アプリ診断21グループが成功しています。
- CIの音声検証は実WAV生成・速度差・取消・再利用です。音声の実再生は別途ローカルで275件を確認し、CIで実再生したという扱いにはしません。
- タグのコミットとビルド元の差は公開文書のみです。アプリ・ビルド入力が同一であることを照合し、元のビルド記録は変更しません。
- `SHA256SUMS.txt`で添付ファイル、`release-provenance.json`で出所、`verification-summary.json`で検証範囲を確認できます。署名・審査済みの正式版とは区別します。

- 新規保存するプロジェクト形式は1.14、読取可能な最小版はdev.262です。dev.199では開けないため、移行前のファイルを残してください。設定形式は21です。
- 未OCR範囲・ページ／PDF全体の新規認識、ナレーター専用Natural音声、署名済みMSIX・Store配布は引き続き未対応です。
- 文書処理はローカルです。利用者が実行するWebリンク・更新確認の通信は許可します。

# v1.0.0-dev.209：ページ単位の一括処理と操作状態の修正

## 修正内容

- 一括自動リンク・範囲繰り返し・文字検索墨消しは、対象ページのリンク／回転／CropBox情報を優先して待つ。表示していない全ページの完了や特性検査は待たない。仮の座標で候補を作らず、表示中のページはそのまま操作できる。
- 待機中の中止は候補作成だけを止める。共有の文書読込を中止しない。文書切替・編集状態変更後の古い候補は破棄する。
- 自動リンクの重複判定には、候補作成開始後に取り込まれた対象ページのリンクも使う。背景処理へはページ単位の回転・原点を値として渡し、画面スレッドの可変辞書を参照しない。
- OCR領域に追従するリンクをロックする際、未保存の最新OCR表示位置を固定する。対象リンクだけを更新し、全OCRページを保存し直さない。ロック・Undo・Redo後に枠が古い位置へ戻らない。
- リンク入力を「枠選択／文字指定／範囲指定」で切り替えた際、整列・ロック・変形の有効状態を即時通知する。
- 承認済みアイコンを68配置へ追加・置き換え。操作ボタン36、文字矢印／増減等6、実行メニュー26。OCR文字移動／送り幅は文字記号でなくベクター、候補プレビューの拡大／縮小はアイコンと説明ラベルを使用。文字ロックの右クリックアイコンは状態に応じて切り替わる。

## 軽快さ・保守性の境界

文書単位の既存リンク索引と読込処理を再利用し、操作ごとに独立した全文読込を作らない。候補作成は従来どおり1ページずつ処理し、画像を文書全体分保持せず、最大10,000件と中止を維持する。共通アイコンは凍結済みベクター形状を共有する。新しいアイコンフォント／画像ファイル群は追加していない。

これは実PDFすべての処理時間を保証するものではない。保存・出力・ページ構成変更は、安全のため必要な全体読込を引き続き待つ。

# v1.0.0-dev.253 — テーマ・Windows読み上げの最終候補

2026-10-27。[dev.252](v1.0.0-dev.252.md)で追加したテーマ・Windows読み上げを引き継ぎ、墨消し対象の除外を補強した開発版。下記の配布版検証を完了した。正式公開やStore登録を完了した版ではない。

読み上げの墨消し除外では、編集後のOCR枠だけでなく元の枠と明示的な墨消し元領域IDも照合する。枠を移動しても墨消し予定の文字が読み上げに戻らないようにし、未保存の取込OCRにも本来の元座標を保持する。墨消し予定がある文書の配置変更は、再生中の古い対象判定を取消す。関連する回帰条件をCore契約試験へ追加した。

利用者操作：設定の表示タブからテーマを選ぶ。読み上げは「表示 → 読み上げ」から開き、選択部分／現在ページ／現在ページから最後までを選ぶ。再生・一時停止／再開・停止はアイコン、音声と速度は展開欄。通常のOCR枠が非表示でも読み上げ行を一時マーカーで示す。文書とPDF紙面は変更しない。

## テーマ

- 「設定 → 表示 → テーマ」でライト／ダーク／Windowsに合わせるを選ぶ。アプリ全体で保存し、実行中の既存画面にも反映する。
- Windows連動はOSの設定通知を受けて更新する。周期的な監視、PDFの再読込・再描画、ドッキング配置の再構築を追加しない。
- メニュー、ツールバー、プロパティ、一覧、入力、スクロールバー、浮動パネル・タイトルの配色を共通の役割別ブラシへ接続する。既存のアイコン形状と標準操作を保持する。
- PDF紙面の元の色、倍率、OCR座標、出力PDFの色は変更しない。Windowsの高コントラスト設定時はシステム配色を使う。

## 読み上げ

- 「表示 → 読み上げ」でモデルレスの操作画面を開く。範囲は選択したOCR文字・行・段落／現在ページ／現在ページから最後まで。
- 再生・一時停止／再開・停止、導入済み音声と速度の選択を提供する。音声・速度はアプリ全体で保存し、文書は未保存扱いにしない。再生状態は保存せず、起動時に自動再生しない。
- 未保存の修正文、読み順、明示的な読み仮名、読み上げ参加属性を利用する。削除済み・意図的な空文字を原文で復活させず、元PDFとの二重読みを避ける。
- 未読込ページでは既存の隔離ワーカーから文字と座標だけを必要時に取得する。全ページの画像生成やOCRを開始条件にしない。画像だけのページにOCRを自動実行しない。
- 読み上げ行を独立した一時マーカーで示す。OCR枠が非表示でも見分けられ、通常の選択を上書きしない。連続読みは対象ページの実際の表示完了を待ってから発声する。
- 文書・ページ構成・対象本文の変更は古い音声と取得を取消す。墨消し予定がない文書の位置だけの調整では、本文の再走査をせずマーカーを追従させる。
- 音声エンジンは画面を開いた時に遅延初期化する。通常の起動やPDF読込へ音声列挙を追加しない。UIとは別のSTAスレッドでWindows音声を制御する。

## 互換性・依存資源・制限

プロジェクト形式1.12／最小読込dev.243／設定21を維持する。テーマ・音声・速度は省略可能な設定で、旧設定には既定値を使う。読み上げのために文書形式は変更しない。

MicrosoftのSystem.Speech 10.0.14（MIT）とライセンスを追加し、公式NuGetのSHA-512、実DLL・ライセンスのSHA-256を照合して依存ロックへ登録した。音声モデルは同梱・導入せず、Windowsの既存SAPI音声を利用する。SAPIとナレーターの音声一覧が一致するとは扱わない。音声ファイル出力やルビの親文字への推測関連付けは含まない。

実際の日本語合成はWAVへ向けて試験し、スピーカーでの再生はしていない。Windows連動は設定値の読取と模擬通知で検証し、端末のテーマ設定を変更していない。クリーンOS、署名、Store登録、MSIXの実導入・更新・アンインストールは未検証で、正式公開条件として残る。

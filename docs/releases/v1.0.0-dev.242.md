# v1.0.0-dev.242 — 再OCRの画像ズームと候補の手修正

2026-10-25。製品版`1.0.0-dev.242`、数値版`1.0.0.242`。GitHub公開版の更新ではない。

## 変更

- 再OCR確認画面で、原画像を初期に枠内へ縮小して表示。拡大／縮小、Ctrl＋ホイール、100%、全体表示と標準スクロールバーを追加する。全体表示中はリサイズに追従する。倍率だけでPDFの再描画・OCRを実行しない。
- 候補の入力欄と認識結果への復帰を追加し、修正後の文字を赤い差分で確認できるようにする。候補の編集・画像操作・キャンセルでは文書を変更しない。空・改行／制御文字・512テキスト要素超は適用せず、不正な貼付けは切り捨てず拒否する。
- 手修正後は同じ画像で文字サイズを非同期調整してから適用する。文字と配置を1回のUndoで戻せる。元OCR、行高、回転、読み順、ロック・古い結果の拒否を維持する。モデルの信頼度は捏造しない。
- 正解辞書／再学習は未実装の将来案として整理した。現在の修正から他の行を勝手に置換したり、画像や正解を蓄積・送信したりしない。設定／プロジェクト形式・依存資源を変更しない。[設計と正解情報の活用案](../RapidOCR-Line-Recognition.md)。

## 検証・配布

- 最終Releaseソリューションビルドは警告0・エラー0。契約テスト51件、アイコン／フッター規約335件、ソース／配布版管理17／18件を通過した。
- 最終ソース／配布版の実RapidOCR診断は各159件。既存の日本語モデル推論・句読点・繰り返し時の余白保持・固定／古い結果の拒否・プロジェクト保存に加え、4096×100と100×512の画像の初期フィット、リサイズ、倍率操作、100%、同じ画像の再利用、18 DIPの候補編集、認識結果への復帰、不正な貼付け拒否、512 Unicodeテキスト要素、Enterで誤適用しないこと、日英文言と生の文字保持、差分の赤字を検証した。
- 実際の確認画面で手入力した候補を非同期調整後に適用した。文字列・送り幅・行外形を照合し、元OCR・行高・回転・読み順を保持、Undo／Redo各1回で文字と配置を一緒に戻せた。手修正にモデルスコアを作らず自動適用を拒否し、キャンセル・過去のチケットも変更を加えなかった。画像操作・入力・閉じるだけでは文書状態と元のページ画像は変化しなかった。

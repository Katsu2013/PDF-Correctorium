# v1.0.0-dev.206：リンク配置・一括処理・操作設定

## 実装内容

- 矩形リンクをCtrl+クリックで複数選択し、最初の枠を基準に整列・幅／高さ／サイズを統一。ロックは移動・サイズ変更・整列・削除を禁止し、移動先の変更は許可します。選択・変更・削除はUndoに対応します。
- 目次などの指定ページで、末尾の半角／全角数字と指定したページ番号差から内部リンク候補を作成。元ページと移動先を確認し、チェックした候補のみ追加します。既存リンクとの重複は既定で除外、文書外の移動先は適用不可です。クリック移動はAlt+クリックへ変更し、Ctrl+クリックと区別しました。
- 一括墨消しは、選択範囲の複数ページへの繰り返しと、編集済みOCR／PDF可視文字の文字列検索の両方を実装。範囲の色・形状を維持し、ページサイズ／回転が異なる場合は適用不可にします。検索では一致した字形だけを指定し、同じ行の範囲外文字を保持します。
- 候補一覧は仮想化し、プレビュー画像は現在選択した1ページのみ読み込みます。判定はバックグラウンドで行い、中止可能・最大10,000候補。全選択の集計を1回にまとめ、条件変更時は古い候補・プレビューを無効化します。適用は1回のUndoで取り消せます。
- 設定の「編集 → 初期編集モード」で新規文書のモードを選択。プロジェクト保存済みのモードを優先し、旧プロジェクトは設定へフォールバックします。モードだけの変更は未保存扱いにせず、通常保存で記録。一時操作・OCR編集単位は保存対象に含めません。
- メイン／ページ表示ツールバーのボタン・入力部品は右クリックのチェック付きメニューで表示を切り替え、アプリ共通で保存。全非表示でも表示メニューで復元し、編集モードは編集メニューでも選べます。不要な区切り線を除き、浮動ツールバーのサイズを内容に合わせます。ドッキング構造は再構築しません。
- dev.205でソースだけ反映していた承認済みアイコンを含めてビルド。プロパティの水平線を部分的に整理しましたが、後日の利用者確認でOCRモードの二重線が残っていたため、[dev.207](v1.0.0-dev.207.md)で修正しました。

詳細は [確定仕様・操作方法](../Next-Implementation-Plan.md) を参照してください。

## 互換性と注意事項

- プロジェクト形式1.11、最低読込版dev.206。リンクロックと編集モードの保存に対応したため更新しました。形式1.0〜1.10は引き続き読込可能。設定形式は19です。
- 自動リンクは末尾の整数に限定した候補作成です。ローマ数字や任意書式の意味判断には対応していません。必ず移動先を確認してください。
- 検索墨消しは文字列検索で、個人情報自動検出・OCR認識の実行ではありません。画像だけの文字や認識誤りは見つからず、結果ゼロは機密情報不在の保証になりません。
- プロジェクト・元PDF・バックアップは墨消し済み成果物ではありません。配布するPDFは、情報消去・範囲外OCR保持・検証を行う既存のPDF出力経路で作成してください。
- OCR領域に追従するリンクと複数行の文字リンクは整列対象外。ロック中の枠は固定し、OCR枠の編集による移動にも追従させません。
- 既存のページ表示保存・文書初期表示の優先順位は変更していません。コマンド検索・ショートカット専用プリセットは保留です。

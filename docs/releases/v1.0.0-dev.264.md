# v1.0.0-dev.264 — 段落編集の外枠

2026-10-29。

段落編集時に、各段落のまとまりを薄い外枠で表示し、選択中の段落だけ濃く強調します。行ごとの枠・塗りを抑えて、段落の範囲を把握しやすくします。既存のOCR枠表示と不透明度設定に連動し、本文を塗りつぶしません。PDF出力へ枠を追加しません。

自動判定・手動指定とも既存の段落選択と同じ分割を使います。縦書き・回転行・空の編集行を扱い、削除済み行は対象外です。現在ページに1個の描画層を置き、選択・ズーム・透明度だけの変更では分割と外接範囲を再計算しません。モード変更・ページ切替で旧行の購読を解放します。全ページの先読みやPDF再描画を増やしません。

「まとめる」の方向混在・非連続選択の条件変更は回答待ちであり、今回の枠表示に含めません。プロジェクト形式1.14／最小読込dev.262、設定21と依存ライブラリは維持します。[採用設計](../Paragraph-Outlines.md)。

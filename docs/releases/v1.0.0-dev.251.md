# v1.0.0-dev.251 — .NET同梱配布と見開き移動の競合修正

2026-10-27。dev.250の.NET/VC同梱、自己完結型ZIP、MSIX生成、Store／App Installerへ委譲する更新経路を引き継ぐ開発版です。以下の配布内容・回帰試験まで完了しています。

dev.250の通し試験で、背景OCR辞書が準備済みキャッシュを発行すると、見開き移動の結果まで破棄される条件を確認しました。2回の単独再試験は成功した一方、ソースに広すぎるモデル参照一致の条件が残っていたため修正しました。連続表示と見開き移動で文書世代・ProjectId・ページ数・対象／相方ページ対応を照合し、関係のないキャッシュ更新では破棄しません。回転など対象ページが変われば古い見開きを反映せず、読込中は元の表示を保ちます。

診断は固定2秒の待機仮定を使わず、移動処理自体の完了を上限付きで待ちます。背景モデルの差替えを意図的に発生させる成功条件と、対象・相方の回転変更を拒否する条件を追加しました。

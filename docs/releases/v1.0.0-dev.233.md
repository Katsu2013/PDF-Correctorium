# v1.0.0-dev.233 — 余白付き1回の再認識へ統一

## 内容

- これまでの「2回目」と同じ、白余白を左右各2px・上下各3px追加した画像だけを認識する。追加前の画像による1回目の推論は行わず、1要求につき認識1回とする。空結果の際に裏で別条件へ戻して再実行する処理も置かない。
- 認識結果の受け渡しを1候補へ整理し、確認画面の「別の画像条件での候補」を削除する。表示、適用、文字サイズ調整は同じ1つの結果を使用する。2結果の合成・多数決は行わない。
- 既存文字を同じ順序で保持できる、一意な挿入だけを自動補完の候補とする。単一結果の行平均スコア0.95以上・追加文字0.98以上・画像上の根拠という既存の閾値を維持する。別余白条件との一致チェックは廃止するため、従来と同じ安定性検査を続けているとは扱わない。スコアは正答率ではなく、正解の保証もない。
- 置換・削除・曖昧な追加・手修正済みの行は確認を挟む。固定、古い結果の拒否、元のOCR保持、再OCR後の行全体の画像調整、1回のUndo/Redo、ステータスバーでの進捗・中止は維持する。
- OCRモデル・辞書・外部依存、プロジェクト1.11／最小アプリdev.206、設定21は変更しない。新規の範囲・ページ・PDF全体OCRは別件の確認待ちで、今回に含めない。

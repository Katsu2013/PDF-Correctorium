# PDF Correctorium v1.0.0-dev.199（開発版）

前回公開版 **v1.0.0-dev.171 から dev.199 まで**の変更点をまとめています。

## 主な追加・改善

### ページ整理としおり

- 全ページ・現在ページ・選択ページ・奇数／偶数ページ・指定範囲の抽出、1ページずつ／指定枚数／指定開始位置による分割に対応しました。
- 編集中の内容を反映したPDFから抽出・分割します。抽出先に存在しないページへのしおりを除き、残るしおりのページ番号を再対応付けします。親の移動先を除いた場合も、有効な子しおりは保持します。
- 現在ページと同じサイズ、A4・A3・Letterなどの空白ページを挿入できます。

### PDFリンク

- OCR領域とは独立した四角形のリンク範囲を作成できます。
- 文書内ページ移動とHTTP(S)のWebリンクを作成・編集できます。対応できる既存PDFリンクも取り込み、変更・削除して出力できます。
- 既存リンクの編集では元の注釈との対応を保持し、変更後のリンクが重複しないようにしました。
- JavaScript・外部ファイル起動などの非対応動作は実行せず、注意事項として扱います。すべてのPDFリンク形式を編集できるわけではありません。

### ページ番号・ヘッダー／フッター・文字透かし

- 適用範囲、文字列、文字サイズ、色、透明度、余白・配置を指定できます。編集画面の対象ページとPDF出力に反映します。
- 表紙を飛ばし、PDFの2ページ目から「1」を付けるプリセットを追加しました。開始番号や適用範囲も調整できます。
- 奇数・偶数ページで別の配置を選べます。判定は**表示する番号ではなく、出力PDFのページ順**を基準にします。
- 設定画面に奇数・偶数の配置を確認する2つの簡易プレビューを追加しました。
- 日本語を印字できるよう、Noto Sans JPをOFLライセンスとともに同梱しました。

### プロジェクトの復旧

- 起動時に利用できる未保存作業の復旧データを案内し、開く・削除する操作に対応しました。
- 元PDFが移動・紛失した場合の理由表示と再選択に対応しました。誤ったPDFへの編集適用を避けるため、再選択したファイルは記録済みサイズ・SHA-256が一致するものに限定します。
- 旧プロジェクト形式1.5／1.6の読み込みを修正しました。

### ツールバーと作業パネル

- ページ移動、拡大縮小、単一／見開き、スクロール切替を「ページ表示」ツールバーに集約しました。表示モードはトグルボタンで切り替えられます。
- メイン／ページ表示ツールバーを上下左右へ配置し、切り離して使えます。縦配置のページ番号欄をコンパクトにしました。
- AvalonDockを導入し、ページ・しおり・プロパティを独立したパネルとして、移動、タブ化、上下分割、切り離しできるようにしました。
- タブを上部へ配置し、選択表示をアプリのデザインに合わせました。
- 再起動や単一／見開き切替時にプロパティの位置が変わる問題、ツールバー移動後の消失、上下に重ねた後の空白・不要な仕切り、浮動ツールバーの大きさを修正しました。
- 移動用の点列を詰め、ページ一覧の外側余白とPDF編集領域の白い外周余白を削減しました。

### 入力PDFの注意事項と配布構成

- フォーム・XFA、署名、添付ファイル、JavaScriptなどの動作、レイヤー、ポートフォリオ、増分更新、フォント埋め込みなどの構造を調べ、注意事項の案内を拡充しました。検出は網羅的な安全性保証ではありません。
- qpdf関連ファイルを `components/qpdf/`、日本語フォントを `components/fonts/` にまとめました。PDFiumは `runtimes/`、AvalonDockはアプリと同じフォルダーに配置します。
- AvalonDockの追加言語リソースは日本語の `ja/` のみに絞りました。NDLOCR-lite本体・認識モデルは同梱していません（認識結果の取り込みに対応）。

## 互換性・注意事項

- Windows 10／11 x64向けの開発版です。**.NET 8 Desktop Runtime（x64）**が必要です。ZIPを新しいフォルダーに展開し、`PdfCorrectorium.exe` を起動してください。
- 保存形式は **1.9** です。旧形式1.0～1.8を読み込めますが、新しく保存した形式1.9はdev.171などの旧版では開けません。必要に応じて元プロジェクトを別名で残してください。
- 設定画面のプレビューは配置確認用の模式図であり、実際のPDFを縮小描画したものではありません。編集画面では編集中ページの表示を確認してください。非アクティブな見開き相手ページ・連続表示ページの装飾表示は検証対象外です。
- 画像透かしや任意角度の文字透かし、既存本文の一般的な直接編集、新規OCR認識エンジンの内蔵は今回の対象外です。
- 自動診断が通っていても、すべてのPDF・操作・ドッキング先を保証するものではありません。重要な文書は出力後に内容・リンク・墨消し結果を確認してください。

## English summary

This prerelease includes changes since v1.0.0-dev.171: page extraction/splitting and blank-page insertion; bookmark cleanup; editable internal and HTTP(S) links; text page numbers, headers/footers and watermarks with bundled Japanese font support; cover skipping and odd/even placement; project recovery and verified source-PDF relocation; AvalonDock-based workspace docking improvements; and expanded input-PDF warnings.

Requires Windows x64 and the .NET 8 Desktop Runtime. Newly saved format-1.9 projects require a compatible application version. The two dialog previews are schematic placement previews. Existing dev.199 binaries are reused without rebuilding.

## 変更内容

- 再OCRの原画像枠がウィンドウの余った高さを占有しないようにした。初期高さは行画像の縦横比と表示幅から決め、64～180 DIPに制限する。短い横書き行は低く、縦書き・縦長画像は高めに表示する。ウィンドウも内容に合わせた初期高さにする。
- 修正入力欄は最小34／最大76 DIPとし、文字サイズ18 DIPは維持する。長文は入力欄内でスクロールする。小さいウィンドウや翻訳による折返しでは本文側をスクロールさせ、適用・閉じるボタンは下部に残す。
- 共通の通常ボタンは内側余白12,6→8,3 DIP、外側3→2 DIP。最小高さ30 DIPと既存アイコンは維持する。下部の確定／キャンセル等は引き続きアイコンなし。
- 設定画面の外側・タブ内側16→12 DIP、節間の過大な余白を12／10 DIPへ整理。OCR品質分析とOCR辞書の外周、フィルター間隔、操作ボタンの余白もコンパクト化した。
- ツールバーの利用者指定サイズ、ページ／OCR文字の表示倍率、一覧の文字サイズ・行余白、文書画像・認識用余白、OCR処理そのものは変更しない。表示変更による追加のPDF描画・OCR・辞書集計はしない。

プロジェクト形式1.12、最小読込版dev.243、設定形式21、依存ライブラリは変更なし。共通OCR辞書と手修正・Undoの仕様はdev.244を引き継ぐ。

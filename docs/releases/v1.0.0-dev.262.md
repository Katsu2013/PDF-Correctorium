共通辞書を旧版で失わないよう、保存形式を1.14／最小読込dev.262へ更新します。旧1.0～1.13は読めます。設定形式21とPDF/OCR・音声の依存資源は維持します。[設計](../Shared-Readings-And-Docked-Speech.md)。

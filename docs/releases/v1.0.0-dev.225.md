# v1.0.0-dev.225 — 文書データ出力・正規表現墨消し候補

2026-10-14。[追加された将来候補と既存機能の重複](../../wiki/Roadmap.md)を先に照合し、比較的小規模で校正作業に役立つ4機能を実装した。[設計と受入条件](../Document-Exports-and-Regex.md)を参照。

## 追加内容

1. 編集後OCRのTXT：現在のページ順・読み順、削除領域除外、範囲指定とページ見出し。新たなOCR認識や可視本文抽出ではない。
2. 独自コメント・タグのCSV：文書全体の対応状態・重要度・作成者・日時を含むUTF-8 BOM付き一覧。引用符・改行をエスケープし、表計算の式注入を防ぐ。標準PDF注釈の取込・XFDF交換ではない。
3. 完成ページPNG/JPEG：墨消し・装飾・ページ編集を反映して既存経路で生成・検証したPDFから保存。72〜300 DPI、JPEG品質指定。入力コピーは処理単位、画像は1ページずつ。選択ページだけでも初期のPDF生成・検証は全文書が対象。
4. 正規表現の一括墨消し候補：既定は従来の完全一致。範囲・大小文字・候補確認・選択適用・1回のUndoを共有。式長・時間・文字量・件数を制限し、無効式・ゼロ長・上限超過時には部分結果を適用できない。

ファイル → 作業データ・ページ画像の出力から3形式を選ぶ。TXT/CSVは墨消し予定の情報を含み得る作業データとして常時警告し、安全な共有成果物とは扱わない。出力中は進捗・中止を表示、入力を固定する。ダイアログ下部は文字のみ、メニューは既存Exportアイコンで統一。

## 保全・互換性

AppContainer・Job制約・検証後確定は維持。原PDF／プロジェクト／認可済みOCR入力を上書きしない。TXT/CSVは一時ファイルから確定し、画像は生成した専用サブフォルダーだけに保存、取消時は自分が作ったファイルだけを片付ける。プロジェクトにある未認可のパスヒントを調査しない。画像1枚は最大8,192画素／辺・2,000万画素・64 MiB、TXT/CSVも64 MiB上限。画質を黙って下げない。

新しい永続データ項目はなく、プロジェクト形式1.11／最小読込dev.206／アプリ設定20を維持。元PDF・プロジェクト・TXT/CSV・バックアップの機密情報消去は保証しない。標準注釈・フォーム・CropBox編集・サニタイズ等を実装済みとはしない。

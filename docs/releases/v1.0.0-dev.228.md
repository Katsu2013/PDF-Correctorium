# v1.0.0-dev.228 — 枠非表示時のキーワードマーカー

## 修正

dev.227ではOCR枠を隠すと検索・類似語の一致箇所の塗りまで消え、移動先を判別しにくくなっていました。一致箇所のマーカーを通常の枠から分離し、該当キーワードだけに半透明の黄色（40%アルファ）を表示します。

- 類似語、OCR品質分析、通常のOCR検索で共通の表示を使用します。
- OCR枠が非表示、または枠の不透明度0%でも目印を表示します。青枠・他の文字セル・編集ハンドルは再表示しません。
- 次の候補への移動で一致範囲が切り替わります。対象文字の編集や既存の検索強調解除で消えます。
- 既存のUnicode文字セル、縦書き座標、回転変換と字形キャッシュを利用し、PDF再読込や追加の全ページ解析をしません。
- マーカーは画面表示だけで、未保存状態、Undo、PDF出力に影響しません。データ互換性と設定形式は変更していません。

# v1.0.0-dev.203 — 表示ページのリンクを優先して読み込み

リンク枠が、文書全体のリンク確認完了まで表示されなかった待ち方を変更しました。

- 現在ページ、見開きの隣接ページ、連続表示の表示面を優先して読み込み、準備できたページから枠を表示・編集できます。
- 未表示ページは小分けでバックグラウンド確認します。右ペインで準備状況と進捗を表示します。
- 保存済みリンクは再利用し、座標情報だけ取得します。ページ参照・継承属性・名前付き移動先は文書単位のキャッシュを共有します。
- 後続の読み込みで編集中の枠を作り直さず、Undo／Redoで後から発見したリンクを消さないようにしました。先に変更・削除した元リンクも保持します。
- 保存／PDF出力／ページ構成変更は全ページの確認を待ちます。失敗は理由を表示して不完全な保存を止め、文書変更時は旧処理を取り消します。
- OCRページをまだ持っていないプロジェクトでも、ページ配列を使ってリンクを書き出すようにしました。

プロジェクト形式1.10、最小対応アプリdev.200は変更しません。リンク枠の位置揃え・サイズ合わせ・ロックは仕様確認待ちで、この修正には含めていません。

実行中の小分け処理や名前付き移動先の参照解決は完了を待つため、すべてのPDFで瞬時表示を保証するものではありません。大型実ファイルの速度比較、利用者の実ファイルでの操作は未検証です。

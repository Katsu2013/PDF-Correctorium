# dev.281 音声生成と実再生の検証範囲を明示

- dev.280のCIではアプリ診断20グループが成功し、テーマ・音声だけがMediaPlayerでの再生段階で失敗した。音声生成までは進んだが、描画・音声出力側の詳しい原因は未確定。
- CIは明示的なSynthesisOnlyプロファイルとし、実際のWindows APIでWAV生成・0.5刻みの速度差・取消・再利用を検証する。日本語の読み方、段落、PDF出力やUIの論理検証も継続する。
- ローカル検証の既定値はNativePlayback。実再生、タイミング付きキュー、一時停止・再開、再生中取消も確認する。
- 検証結果にはプロファイルとnativeSpeechPlaybackVerifiedを記録し、CIを「実再生を検証済み」と扱わない。生成だけの入口は診断の明示有効化とWAV出力先を必須にする。
- 通常の読み上げはこれまでどおりWindowsの再生機能を使う。再生失敗時には空の例外ではなく、MediaPlayerのエラー種別とHRESULTを残す。
- 新規アプリリリース、dev.274の既存配布物差し替えは行わない。

直接配布の更新確認は固定HTTPSの情報を非同期で取得して導入済みの保護されたPackage IDと照合する。新しい版があるときだけ利用者へ案内し、通常の保存確認と終了が完了してからWindowsの更新画面へ引き渡す。通信失敗、キャンセル、保存失敗では置換や強制終了を行わない。

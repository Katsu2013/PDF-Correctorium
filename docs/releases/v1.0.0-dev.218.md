- ZIP内JSON・サムネイル・内包元PDFは展開後の実バイト数と宣言サイズを検査する。無圧縮エントリのサイズ偽装を読み込み中に拒否し、サムネイル全体の実読込量も制限する。JSON全体を別のMemoryStreamへ複製しない。

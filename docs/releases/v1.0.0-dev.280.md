# dev.280 CI音声診断の前提と版情報を統一

- dev.279のCIではページ履歴診断が成功。前回の失敗は再現せず、原因は確定していない。記録は保持する。
- 続く音声診断は「日本語音声が必須」という診断側の前提で失敗。Windows ServerのCIには日本語音声がない。
- 日本語音声を優先し、未導入なら導入済みのMicrosoft音声で実音声を検証する。実WAV、キュー、一時停止、再開、取消、0.5刻みの速度比較は省略しない。日本語の読み方・段落・PDF出力の検証も残す。音声が1つもない場合は引き続き失敗にする。
- アプリ診断21グループはすべて実行して失敗を集約する。1件でも失敗すれば全体は失敗し、成功の報告やZIP生成へは進まない。
- CIでInformationalVersionへ自動付加されていたGitハッシュを止め、規則どおりバージョン本体だけに統一。公開検査もハッシュを除いて比較する扱いを廃止し、完全一致を要求する。コミットはbuild-info.jsonに記録する。
- 新規リリース、dev.274の配布ファイル差し替えは行わない。設計の機能基準はdev.278 PDF。

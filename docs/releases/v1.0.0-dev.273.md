# PDF Correctorium v1.0.0-dev.273 — dev.199からの累積更新

前回GitHub公開版 **v1.0.0-dev.199（2026-09-30）** から、今回のリリース候補までの変更です。dev.200～271は途中の開発・検証記録であり、それぞれをGitHubで公開したという意味ではありません。今回はコミット直前までの準備で、コミット・push・タグ作成・公開は行いません。

## OCR校正・再認識

- RapidOCRを同梱し、選択した横書き1行を原画像から再認識できます。明確な文字抜けの補完と、文字が異なる場合の確認を分け、固定や手修正済みの内容を保護します。
- 再認識の確認画面で画像の全体表示・拡大縮小と、適用する文字の手修正ができます。差分を赤く表示し、適用時は文字幅も画像から調整します。
- 認識画像の周囲に余白を付けつつ、適用する文字範囲には余白を含めません。先頭・末尾だけ幅が広がったり、再実行のたびに余白が増える問題を修正しました。
- 目次の長い点線、英数字と日本語が混在する行などの文字境界推定を改善し、1文字ずつ繰り返し実行しないと整わない状況を修正しました。
- 資料別のOCR辞書に正解語・訂正ルール・無視語を保存できます。英数字と登録した日本語語句を対象とし、同文字数の明示登録ルールは自動適用を許可できます。モデルの再学習ではありません。
- 類似語・誤認識候補、文字数の外れ値、キーワード幅の分析を改善。文字種・幅・高さ・方向を考慮し、固定済み領域を除外できます。部分修正後も残りの候補を保持し、OCR行の位置変更だけで全文再分析を要求しません。
- 一覧の並べ替えを保持し、現在の語・修正候補を拡大表示します。列見出しの右クリックで表示列を切り替えられます。

## リンク・一括処理・書き出し

- 既存PDFリンクを専用モードの枠・一覧から選択して変更・削除できます。文書内ページ移動とHTTP(S)を対象とし、JavaScript・外部ファイル起動等の未対応動作は実行しません。
- 矩形や文字選択でリンクを追加し、選択したOCR文字からも設定できます。リンク枠の表示切替、複数選択、整列・幅／高さ／サイズ合わせ、移動・サイズ変更・削除のロックに対応します。
- 目次等の末尾ページ番号から内部リンク候補を作り、移動先・範囲を確認した候補だけを追加できます。文字選択範囲は行ごとのクリック範囲を保持します。
- 同じ位置の範囲反復と、文字列検索による一括墨消しを追加。候補確認・選択適用・Undoに対応します。
- OCR作業文字のTXT、コメント一覧のCSV、完成ページ画像のPNG／JPEGを書き出せます。**TXT・CSVは墨消し予定の情報を含み得る作業データ**です。共有用の完成PDF・完成ページ画像とは区別します。

## 読み上げ・段落・読み方

- Windows標準のローカル音声で、選択部分・現在ページ・現在ページから末尾までを読み上げます。再生・一時停止・停止、段落／行単位の前後移動、音声選択、0.5刻みの速度指定に対応します。
- ヘッドホンのツールバーボタンから読み上げパネルを開けます。パネルのドッキング・切り離し・自動収納に対応します。
- OCR行を保持したまま「同じ段落にまとめる／行ごと／自動」を設定し、保存・Undoできます。段落の外枠を薄く表示し、選択中は強調します。横書きのChapterと縦書きの1を明示的にまとめた場合も、読み上げに反映します。
- プロジェクト共通の読み方辞書と行ごとの例外を設定できます。画面上の確認用ルビをダブルクリックして修正できます。確認用ルビは出力PDFへ描画しません。
- PDFには原文の検索・コピーを維持したまま読み方情報を保存します。**外部リーダーが登録どおりに発音する保証はありません。** Node.jsのドットの発音や短い間等、検証したリーダーによる違いは[互換性記録](../Pdf-Reading-Interoperability.md)を参照してください。

## 操作画面・表示・読み込み

- ライト／ダーク／Windowsに合わせるテーマを追加。PDF紙面と出力色は変更せず、メニュー、ツールバー、アイコン、境界色を切り替えます。文書を開かず設定できます。
- プロパティをOCR・校正、リンク、墨消し、コメント・タグへ分離。操作ガイド、ボタン、余白と説明の重複を整理し、ダイアログ下部は文字だけのボタンへ統一しました。
- パネルの閉じる・再表示・配置復元を修正。左右それぞれの一括収納、個別の固定、後から開いたパネルの収納方針、アイコン付きタブと展開幅を揃えました。
- ツールバーのボタン表示を右クリックから選べ、アプリ共通設定へ保存できます。編集モードの初期値とプロジェクト保存時のモードを記憶し、モードだけの変更は未保存扱いにしません。
- PDF／プロジェクトは最初のページと表示中ページのリンクを優先し、残りの検査を背景で進めます。進捗はステータスバーへ集約します。
- OCR枠の表示・不透明度を調整できます。枠を非表示にしても、検索・類似語から移動した対象は半透明マーカーで判別できます。

## 安全性・実行基盤・配布

- PDFium／qpdfの文書処理をネットワーク能力なしのAppContainerへ隔離し、資源・入出力を検査します。隔離できない場合は通常権限で続行しません。
- プロジェクト・OCR・しおり・画像・ワーカー応答の入力検査と、墨消し後の文字・古い代替情報の残存検査を強化しました。元PDF・既存の完成出力を、失敗・取消で置き換えない方針を維持します。
- .NET 8から.NET 10へ移行し、自己完結型ZIPへ.NET 10.0.14を同梱。新しいZIPでは別途.NET Runtimeの導入は不要です。PDFium 158.0.8125、qpdf 12.4.2、AvalonDock 4.74.1等を固定し、ライセンス・ハッシュを照合します。
- 全配布ファイルの一覧から公開用フォルダーとZIPを作り、完成ZIPも全件照合します。利用中フォルダーのPDFキャッシュ・設定・ログを混ぜません。
- 診断7プロジェクトとCIを揃え、版番号・入力指紋・出所・配布物を照合します。設計PDFの固定版表記も廃止しました。

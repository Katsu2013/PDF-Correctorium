# v1.0.0-dev.236 — 固定済み外れ値の絞り込みとフォント通知

2026-10-23。ソース版`1.0.0-dev.236`、数値版`1.0.0.236`。GitHub公開版を変更した記録ではない。

## 変更

- 文字数の外れ値一覧に「固定済みの領域も表示」を追加。初期はオフ。領域全体の位置・サイズ固定が対象で、文字単位の固定だけでは非表示にしない。
- 分析結果を保持したまま表示だけを切り替え、固定変更・Undo／Redoに追従する。「固定」列と非表示件数を表示し、並べ替えを維持する。通常の行移動では一覧を走査・再構築せず、表示切替だけでは未保存にしない。統計の比較対象から固定領域を取り除かない。設定は分析画面内で有効。
- 未埋め込みフォントの通常の注意はOCRプロパティ内の確認ボタンへ移動。既存の全ページ検査で、フォントの全使用がPDF描画モード3の透明テキストだと確認できる場合は通知を省略する。可視使用が混在する場合、クリッピング、未知・検査不完全の場合は省略しない。文書のプロパティのフォント一覧には残す。
- 署名、セキュリティ、検査失敗など他の注意事項は上部に残し、重大なフォント警告もコードだけでは隠さない。全ページの追加走査やOCR実行は増やさない。
- 新規の範囲／ページ／PDF全体OCRは未実装。プレビュー後の一括追加、ルビは独立した文字枠という確認結果を[計画書](../RapidOCR-New-Recognition-Plan.md)へ反映した。モデル追加・形式変更はない。

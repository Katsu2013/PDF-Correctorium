# v1.0.0-dev.207：アイコンの反映漏れ・プロパティ区切り線の修正

## 修正内容

- リンク表示／編集のツールバーに残っていた旧式のインライン形状を、共通の横向きリンク記号へ変更。表示は四隅の枠で区別し、追加は透明な余白を持つ＋を使用します。
- ファイルを開く・保存・PDF出力・OCR読込、編集モード、単一／見開き／連続スクロール、ページ挿入／削除／回転、しおり、OCR領域、リンク関連のメニューへ対応するアイコンを設定しました。
- リンクプロパティの編集／削除／移動／ロックと、9種類の位置・サイズ合わせボタンへアイコンを追加。文字ラベル、アクセスキー、ツールチップは残し、ラベルは狭い幅で折り返せるようにしています。
- OCRモードで文書注釈の下に並んでいた2本の水平線を1本にしました。リンク・墨消しモードにはOCR用の末尾区切り線を表示しません。
- 共通描画部品は辞書内のベクター形状を参照し、Freezeした描画形状だけをキャッシュします。UI要素や画像ファイルを共有・生成しません。
- 「PDFを開く」「プロジェクトを開く」、左右90度回転の既存デザインを維持。コマンドやリンク編集機能の動作変更はありません。

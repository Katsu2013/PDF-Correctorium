### 初回失敗・未解決事項

- 初回コンパイルで新規診断の文字選択取得APIの誤りを検出して修正。契約テストの初回1件失敗はテスト用頻度が既定の5倍条件を満たさなかったため、入力を修正しました。判定条件は緩めていません。
- 診断実行中のExportDiagnostics再ビルドには実行ファイルのロックによるMSB3026再試行警告がありました。終了後の最終再ビルドは警告0です。
- **配布セキュリティ試験の初回は失敗しています。** 他のアプリ診断と並行実行中、隔離PDF出力ワーカーが状態ファイルを`File.Move(..., overwrite: true)`で置換する際に`UnauthorizedAccessException`となりました。`outputs/verification-dev222-security-packaged`の中間成果物を保持しています。同じ配布DLLを用いた単独再実行は125件成功しましたが、原因確定・不具合解消を意味しません。既存コードでは親の状態読取ハンドルが`FileShare.Read`で開かれるため、置換との競合の可能性があります（今回の失敗との因果関係は未確定）。この追加機能では隔離／出力コードを変更しておらず、通常権限へのフォールバックも追加していません。公開品質判断ではこの既存経路の追加調査が必要です。

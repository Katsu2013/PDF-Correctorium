# v1.0.0-dev.250 — .NET同梱ZIP・MSIX生成・更新経路

2026-10-27。中間検証版。MSIX／ZIP内容9項目、版管理32項目、ネイティブ216項目と隔離証明は成功しましたが、通し試験の設定診断が107項目後に見開き切替で失敗しました。失敗を保持し、[dev.251](v1.0.0-dev.251.md)で修正を継続しました。Storeアカウント／直接配布用証明書が未用意のため、MSIXの正式導入・配信もまだ有効ではありません。

- .NET 10.0.14のCoreとWPFランタイムを同梱する自己完結型へ変更。251個の実行時資源とライセンスを公式パッケージに照合してロック。RID指定でルートへ移るPDFium・ONNX・SkiaSharpも検査対象とし、他アーキテクチャのPDFiumはx64配布から除外。
- PDF／サムネイル用ワーカーにはルート配置のOCR専用ネイティブDLLを複製しない。512MiB上限とAppContainerの権限制限は維持。
- ONNX等のネイティブ依存も確認し、公式qpdf一式に含まれるMSVCランタイム8 DLLをアプリ直下にも配置してロック。開発PCのSystem32からDLLを流用しない。
- 共通ペイロードからZIPとMSIXを生成するツールを追加。Storeの予約版数に合わせ、MSIX版だけは共通の開発リビジョンから導出する。
- MSIXにはデスクトップ実行、ja/en、ブランド画像、PDF／プロジェクトのファイル種類を宣言。既定PDFアプリの書換えスクリプトを入れない。パッケージIDがある場合はportable.markerがあってもユーザーデータを実行ファイル側へ保存しない。
- Store版はStore、直接配布版はApp Installerへ委譲する更新経路と「ヘルプ → 更新を確認」を追加。背景の自前通信や実行ファイル差替え、編集中の強制終了は行わない。直接配布用の.appinstallerは背景確認・起動の必須ブロックなし・自動ダウングレードなしとする。
- 未署名Development MSIXには公開前表示を付け、更新先未設定を明示。通常の信頼された導入に使えると表示しない。
- プロジェクト形式1.12／最小読込dev.243／設定21、現在のバージョン導出規定は維持。

検証結果・配布場所は最終確認後に追記します。[配布手順](../Distribution-Operations.md)、[設計計画](../Distribution-Installer-Store-Update-Plan.md)を参照してください。

# PDF Correctorium v1.0.0-dev.200（開発スナップショット）

前回公開版dev.199からのリンク編集機能の変更です。GitHub公開済みリリースを示すものではありません。

## 変更点

- 「リンク編集」モードを追加。ページ内のリンク一覧と色付き枠から選択し、設定変更・削除できます。
- 「リンク表示」で枠を表示／非表示。リンク編集モード中は常に表示し、それ以外ではOCR編集を妨げません。
- 文書内ページ移動／HTTP(S)リンクを編集。名前付き移動先・間接参照を読み込み、未対応アクションは理由を表示して実行しません。
- 不透明なPDF文字と編集済み透明OCR文字をドラッグしてリンクを作成。複数行・縦書きの範囲は一つの設定にまとめ、PDFには行／列ごとの独立したクリック範囲として保存します。
- 矩形リンクは移動・サイズ変更可能。Delで選択リンクを削除し、Undo／Redoで復元できます。文字入力欄のDelは通常の文字削除になります。
- 単一クリックは選択、Ctrl＋クリックまたは「リンク先へ」は移動、ダブルクリックは設定編集。右クリックからも操作できます。
- 見開き・連続表示でも周辺ページにリンク枠を表示します。
- 既存リンクの元注釈を一意に照合して置換し、二重化を防止。照合が曖昧な場合は推測で削除せず、出力を中止します。
- 既存リンクの説明変更では元の移動先位置・表示方式を維持します。
- PDFの継承回転・非ゼロCropBoxを含む文字選択とリンク枠の座標を補正します。
- 移動先ページを未表示のまま出力してもリンクを保持します。
- 旧リンクのID・削除状態を維持し、取り込み情報・旧矩形の座標を移行します。
- 墨消しと重なるリンクは、共有URI・説明に消去対象の情報が残らないようリンク単位で出力から除外します。高精細画像化する墨消しページでは範囲外の安全なリンクを保持し、編集対象外のアクションは復元しません。元のプロジェクト情報は非破壊です。
- [操作手順](../../wiki/Comments-Tags.md)と[画面設計・図版](../../outputs/PdfCorrectorium-Documentation/docs/03_Screens/03-01_ScreenSpecification.md)を更新しました。

## 互換性

保存形式は1.10です。1.0～1.9を読み込めます。新しく保存したプロジェクトにはdev.200以降が必要です。元PDFは変更せず、プロジェクトと出力PDFへ反映します。旧版へ戻る可能性がある場合は保存前ファイルを保管してください。

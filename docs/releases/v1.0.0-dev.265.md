# v1.0.0-dev.265 — Chapter 1の段落指定と左右別の収納

2026-10-29。

「Chapter」と縦書きの「1」のような方向の混在する項目を、手動で同じ段落に指定できるよう修正します。「行ごと」の後も「まとめる」を利用できます。項目の文字・方向・位置・サイズ・ロックは保持し、段落編集・外枠・読み上げで同じまとまりを扱います。無効な選択の理由はボタンのツールチップに表示します。自動判定や読み上げの保護境界は維持し、非連続選択の並べ替えは追加しません。

自動収納は、操作元やタブグループにかかわらず同じ側の表示中パネルをまとめて行います。固定へ戻す操作は選択パネルだけに適用します。後から読み上げ等を開く場合は同じ側の収納設定に従い、個別に固定したパネルは維持します。もう一度一括収納すると個別固定もまとめて収納します。左右の収納状態・個別固定・×での非表示を次回起動へ保持し、ツールバーや浮動パネルを勝手に移動しません。

保存形式1.14／最小読込dev.262、設定21、依存ライブラリは維持します。[採用設計](../Chapter-Grouping-And-Side-AutoHide.md)。

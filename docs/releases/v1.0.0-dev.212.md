# v1.0.0-dev.212：幅合わせ・高さ合わせアイコンの視認性改善

## 変更内容

利用者が承認した「枠＋両矢印」の再検討案をEqualWidth／EqualHeightへ反映。方向を伝える両矢印を残し、外側の2本の基準線を省き、枠と矢印を透明な余白で分離した。18／22／24px比較で確認した形状・線幅1.8・Roundの端と接合を使用する。

共有リソースの2形状を更新。OCRの該当2ボタンと開発用ギャラリーもActionIconへ変更し、リンク操作と同じ固定24単位の描画・Frozenキャッシュを使う。余白を削って枠を引き伸ばすViewbox描画は、この2操作から除去した。OCR／リンクは24pxアイコンと32pxの操作領域を維持する。操作名、アクセスキー、ツールチップ、整列基準、コマンド、ロック、Undo、PDF出力の意味は変更しない。

PageExtract／BookmarkAddChild／RecalculateReadingOrderの候補は未採用・未反映。ダイアログ下部のアイコン除外も維持する。通常のPDF読込・編集・出力へ文書走査や画像読込を追加しない。

正式なアイコン設計基準、提案／採用履歴、README、実装状況を更新。プロジェクト形式1.11／最低読込版dev.206／設定形式19は変更しない。旧配布フォルダーは変更しない。Gitへのコミット・送信・リリース公開は行わない。

# レビュー記録の読み方

- 各レポートは、タイトルの日付・対象リビジョンに対する監査記録です。
- 過去に「一般公開を推奨しない」と記載された内容が、そのまま現在の判定を意味するわけではありません。
- 過去の失敗を削除したり、再検証せず成功へ書き換えたりしません。
- 最新の対応と未完了条件は[外部レビュー対応表](../docs/External-Review-Response-2026-11-02.md)を参照してください。
- 実際の公開状態は[Releases一覧](https://github.com/Katsu2013/PDF-Correctorium/releases)で確認してください。
